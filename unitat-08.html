Unitat 08 · Curs de Django

El Sistema de Templates

Django Template Language (DTL): herència, tags, filtres i variables de context per generar HTML de manera neta i segura.

En aquesta unitat aprendràs:

  • Estructurar templates amb herència: {% extends %} i {% block %}
  • Usar els tags essencials: {% if %}, {% for %}, {% url %}, {% static %}, {% csrf_token %}
  • Aplicar filtres built-in per formatar dades: dates, textos, nombres
  • Entendre l'escapament automàtic i quan usar |safe de manera segura

◆ Herència de templates i tags fonamentals

El sistema de templates de Django segueix un principi de herència: un template base (base.html) defineix l'estructura comuna de totes les pàgines (navbar, footer, blocs de CSS/JS), i els templates fills estenen i omplen els blocs buits. Això elimina la duplicació i garanteix la consistència de l'aspecte general.

Django busca els templates als directoris definits a TEMPLATES[0]['DIRS'] i, si APP_DIRS: True, també a templates/ dins de cada app instal·lada. La convenció per als templates d'app és app/templates/app/fitxer.html (namespace per evitar col·lisions de noms entre apps).

  • {% extends 'base.html' %} — ha de ser la primera línia del template fill; hereda tota l'estructura del pare
  • {% block nom %}contingut per defecte{% endblock %} — defineix una zona sobreescrivible; el fill sobreescriu posant el seu propi {% block nom %}
  • {{ block.super }} — dins d'un bloc fill, insereix el contingut del bloc pare; permet afegir en lloc de substituir
  • {% include 'partial/navbar.html' %} — insereix un template parcial en el punt indicat; útil per a components reutilitzables
  • {% include 'partial/card.html' with llibre=obj only %} — with passa variables extra; only aïlla el context
  • {% load static %} — carrega el sistema de fitxers estàtics; cal posar-ho al principi de cada template que usi {% static %}
  • {% static 'books/css/estil.css' %} — genera la URL absoluta d'un fitxer estàtic respectant STATIC_URL
  • {% csrf_token %} — insereix el camp ocult del token CSRF; obligatori en tots els formularis amb mètode POST

Tags de control de flux que usaràs a cada template:

  • {% if condicio %}...{% elif altra %}...{% else %}...{% endif %} — condicionals; suporta and, or, not, in, is
  • {% for item in llista %}...{% empty %}...{% endfor %} — iteració; {% empty %} es mostra si la llista és buida
  • {{ forloop.counter }} — índex de la iteració (comença en 1); forloop.counter0 comença en 0
  • {{ forloop.first }} / {{ forloop.last }} — booleans per al primer i últim element
  • {% url 'books:detall' pk=llibre.pk %} — genera la URL per nom de vista (vegeu unitat 07)
  • {% with total=llibres|length %}...{% endwith %} — crea una variable local temporal per evitar recalcular
  • {% comment %}...{% endcomment %} — comentari que no apareix al HTML generat
⚠️ Limitació del DTL

El Django Template Language és intencionadament limitat: no pots cridar funcions amb arguments ({{ obj.metode(arg) }} no funciona), ni fer aritmètica complexa, ni usar Python arbitrari. Si necessites lògica complexa, fes-la a la vista i passa el resultat al context. Això manté els templates nets i els fa segurs.

HTML templates/base.html — template base complet per a bibliapp 
<!DOCTYPE html>
<html lang="ca">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  {# El títol de la pàgina es pot personalitzar a cada template fill #}
  <title>{% block titol %}Bibliapp{% endblock %} — Biblioteca Municipal</title>

  {# {% load static %} cal posar-lo ABANS de qualsevol {% static %} #}
  {% load static %}
  <link rel="stylesheet" href="{% static 'css/estil.css' %}">

  {# Bloc per afegir CSS addicional des dels templates fills #}
  {% block css_extra %}{% endblock %}
</head>
<body>

  <nav class="navbar">
    <a href="{% url 'books:llista' %}" class="navbar-brand">📚 Bibliapp</a>

    <div class="navbar-links">
      <a href="{% url 'books:llista' %}">Llibres</a>

      {# request.user.is_authenticated disponible gràcies al context processor auth #}
      {% if request.user.is_authenticated %}
        <a href="{% url 'books:crear' %}">Afegir llibre</a>
        <span class="navbar-user">{{ request.user.get_full_name|default:request.user.username }}</span>
        <a href="{% url 'logout' %}">Sortir</a>
      {% else %}
        <a href="{% url 'login' %}">Entrar</a>
      {% endif %}
    </div>
  </nav>

  {# Missatges flash (de messages.success, messages.error, etc.) #}
  {% if messages %}
    <div class="messages-container">
      {% for msg in messages %}
        <div class="alert alert-{{ msg.tags }}">{{ msg }}</div>
      {% endfor %}
    </div>
  {% endif %}

  <main class="main-content">
    {# Tot el contingut específic de cada pàgina va aquí #}
    {% block contingut %}{% endblock %}
  </main>

  <footer class="footer">
    <p>&copy; {% now "Y" %} Biblioteca Municipal. Tots els drets reservats.</p>
  </footer>

  <script src="{% static 'js/app.js' %}"></script>

  {# Bloc per afegir JS addicional al final del body #}
  {% block js_extra %}{% endblock %}

</body>
</html>

◆ Filtres built-in, variables de context i escapament

Els filtres transformen el valor d'una variable just en el moment de renderitzar-la. S'apliquen amb el caràcter | (pipe) i es poden encadenar: {{ text|lower|truncatechars:50 }}. Django inclou més de 60 filtres built-in; aquí els més usats en aplicacions reals:

{{ data|date:"d/m/Y" }}

Formata una data. Format ISO: "Y-m-d". Amb hora: "d/m/Y H:i"

{{ text|truncatechars:80 }}

Trunca a N caràcters afegint "…" al final si cal.

{{ valor|default:"Sense dades" }}

Mostra el valor alternatiu si la variable és buida, None o False.

{{ llista|length }}

Retorna el nombre d'elements d'una llista, QuerySet o string.

{{ text|upper }}

Converteix a majúscules. |lower fa el contrari. |title capitalitza.

{{ disponible|yesno:"Sí,No,—" }}

Booleà → text. Tres valors: True, False, None (opcional).

{{ preu|floatformat:2 }}

Format de decimal. :2 → 2 decimals. :-2 omet si .00

{{ html_segur|safe }}

Desactiva l'escapament. Usar NOMÉS amb HTML de confiança.

{{ text|linebreaks }}

Converteix salts de línia en etiquetes <p> i <br>.

{{ llista|join:", " }}

Uneix els elements d'una llista amb el separador donat.

{{ numero|add:5 }}

Suma un valor. Funciona amb enters i strings (concatenació).

{{ text|slugify }}

Converteix text a format slug: minúscules, guions, sense accents.

Escapament automàtic: per defecte, Django escapa totes les variables del template per evitar atacs XSS. Els caràcters perillosos com <, >, &, " es converteixen en entitats HTML. Això vol dir que si una variable conté <script>alert('xss')</script>, el navegador ho mostrarà com a text, no l'executarà.

  • {{ variable|safe }} — marca la variable com a segura i desactiva l'escapament per a ella; usar només amb HTML que tu has generat o validat
  • {% autoescape off %}...{% endautoescape %} — desactiva l'escapament per a un bloc sencer; molt rarament necessari
  • mark_safe() — des de Python (from django.utils.safestring import mark_safe), marca un string com a segur abans de passar-lo al context
📌 Context de la vista

Tot el que passes com a tercer argument de render(request, template, context) és accessible al template com a variable. El context sempre inclou automàticament request, user, messages i perms gràcies als context processors per defecte de Django.

🔮 DTL vs Jinja2

Django admet Jinja2 com a backend de templates alternatiu (configurable a TEMPLATES). Jinja2 permet expressions Python completes i és més potent, però el DTL és el que trobaràs a la majoria de projectes Django i és l'opció per defecte i recomanada per a principiants.

{% block contingut %}

      <a href="{% url 'books:llista' %}">Netejar</a>
    {% endif %}
  </form>
</div>

<p class="resultats">
  {# |length sobre un QuerySet fa un COUNT a la BD, eficient #}
  {{ llibres|length }} llibre{{ llibres|length|pluralize:"s" }} trobat{{ llibres|length|pluralize:"s" }}
  {% if cerca %} per a "{{ cerca }}"{% endif %}
</p>

<div class="llibres-grid">
  {% for llibre in llibres %}
    <article class="llibre-card {% if not llibre.disponible %}no-disponible{% endif %}">

      <h2><a href="{% url 'books:detall' pk=llibre.pk %}">{{ llibre.titol|truncatechars:60 }}</a></h2>

      <p class="autor">{{ llibre.autor.nom }}</p>
      <p class="any">{{ llibre.any_publicacio }}</p>

      {# |yesno retorna el primer valor si True, el segon si False #}
      <span class="badge-disponible">{{ llibre.disponible|yesno:"Disponible,Prestat" }}</span>

      {% if user.is_authenticated %}
        <a href="{% url 'books:editar' pk=llibre.pk %}">Editar</a>

        {# Formulari d'esborrat: cal POST i csrf_token #}
        <form method="post" action="{% url 'books:esborrar' pk=llibre.pk %}"
              onsubmit="return confirm('Segur que vols esborrar aquest llibre?')">
          {% csrf_token %}
          <button type="submit" class="btn-danger">Esborrar</button>
        </form>
      {% endif %}

    </article>

  {% empty %}
    {# {% empty %} és el bloc que apareix si 'llibres' és buit #}
    <p class="sense-resultats">No s'han trobat llibres amb aquests criteris.</p>
  {% endfor %}
</div>
{% endblock %}

</article>

def llistar_llibres(request):

◆ Resum de la unitat

Tags fonamentals

  • {% extends %} — herència
  • {% block %} — zona sobreescrivible
  • {% include %} — parcial reutilitzable
  • {% load static %} — fitxers estàtics
  • {% csrf_token %} — seguretat POST
  • {% url %} — URL per nom
  • {% for/empty %} — iteració
  • {% if/elif/else %} — condicionals

Filtres essencials

  • |date:"d/m/Y" — format data
  • |truncatechars:N — trunca text
  • |default:"text" — valor si buit
  • |length — nombre elements
  • |yesno:"Sí,No" — booleà → text
  • |floatformat:2 — decimals
  • |safe — desactivar escape
  • |linebreaks — salt línia → <p>
