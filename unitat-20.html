◆ Fitxers estàtics: CSS, JS i imatges del projecte

En Django, els fitxers estàtics són recursos que formen part del codi del projecte: fulls d'estil CSS, scripts JavaScript, fonts i imatges de la interfície. No canvien amb l'ús de l'aplicació. En contraposició, els fitxers media (o multimèdia) són els que els usuaris pugen en temps d'execució: fotografies de perfil, documents adjunts, portades de llibres.

Django gestiona els dos tipus de manera completament diferent, i confondre'ls és un error habitual en projectes nous. Els estàtics es recopilen amb collectstatic; els media es desen al disc (o al núvol) en cada pujada.

Estàtics → formen part del codi → collectstatic → servits per nginx/CDN
Media → pujats per usuaris → desats a MEDIA_ROOT → servits per nginx/S3

Configuració de fitxers estàtics

  • STATIC_URL — prefix d'URL per servir els estàtics (p. ex. '/static/'). Django afegeix aquest prefix als paths generats per {% static %}.
  • STATICFILES_DIRS — llista de directoris addicionals on Django busca estàtics durant el desenvolupament (a més de la carpeta static/ de cada app).
  • STATIC_ROOT — directori destí on collectstatic copia tots els estàtics per a producció. No l'uses en dev.
  • collectstatic — comanda de gestió que recull tots els estàtics de totes les apps i els copia a STATIC_ROOT. Cal executar-la abans de cada deploy.
⚠️ Atenció

Mai serveixis fitxers estàtics amb el servidor de dev de Django en producció. El servidor de dev és lent, monofil i no és segur. En producció, usa nginx, Apache o un CDN (CloudFront, Cloudflare) per servir el contingut de STATIC_ROOT.

El tag {% static %} als templates

Per referenciar fitxers estàtics als templates, primer cal carregar el tag i després usar-lo per generar la URL correcta. Això permet que la URL canviï entre entorns sense tocar els templates.

  • {% load static %} — s'ha de posar al principi del template (o del template base) per poder usar els tags de static.
  • {% static 'css/main.css' %} — genera la URL completa: /static/css/main.css. Mai escrius la URL a mà.
  • En templates que hereten de base, el {% load static %} s'ha de repetir en cada fitxer que el necessiti, no n'hi ha prou amb posar-lo al base.
Python settings/base.py + config/urls.py 
# ─── settings/base.py ────────────────────────────────────────
import os
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent.parent.parent

# ── Fitxers estàtics (CSS, JS, imatges del projecte) ──────────
STATIC_URL = '/static/'

# Directoris addicionals de cerca (a més de /static/)
STATICFILES_DIRS = [
    BASE_DIR / 'static',   # carpeta static/ arrel del projecte
]

# Destí de collectstatic (per a producció — no tocar en dev)
STATIC_ROOT = BASE_DIR / 'staticfiles'


# ── Fitxers media (pujats per usuaris) ────────────────────────
MEDIA_URL = '/media/'
MEDIA_ROOT = BASE_DIR / 'media'


# ─── config/urls.py ──────────────────────────────────────────
from django.conf import settings
from django.conf.urls.static import static
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('cataleg.urls')),
]

# Servir fitxers media NOMÉS en desenvolupament.
# En producció, nginx o S3 s'encarreguen d'això.
if settings.DEBUG:
    urlpatterns += static(
        settings.MEDIA_URL,
        document_root=settings.MEDIA_ROOT
    )

◆ Fitxers media: camps de model i upload_to

Els fitxers media es gestionen a través de camps especials als models de Django. FileField accepta qualsevol tipus de fitxer; ImageField és una extensió que valida que el fitxer sigui una imatge vàlida (requereix la biblioteca Pillow instal·lada).

  • FileField(upload_to='documents/') — guarda el fitxer a MEDIA_ROOT/documents/ i desa la ruta relativa a la base de dades.
  • ImageField(upload_to='portades/') — igual que FileField però comprova que el contingut sigui una imatge. Afegeix mètodes .width i .height.
  • upload_to com a string — ruta estàtica. Tots els fitxers van al mateix directori, pot crear caos amb molts usuaris.
  • upload_to com a callable — funció def ruta(instance, filename) que retorna la ruta dinàmica en funció de l'objecte. Molt més flexible.
  • blank=True, null=True — cal posar ambdós si el camp de portada és opcional, per no trencar el formulari ni la base de dades.
📌 Nota avançada

En producció mai serveixis media amb Django directament. Les opcions habituals són: nginx (mapejar /media/ al directori al servidor), Amazon S3 (amb django-storages i boto3), o Cloudinary. El canvi de backend d'emmagatzematge no requereix modificar el model, només la configuració.

Mostrar fitxers media als templates

Un camp ImageField o FileField actua com un objecte FieldFile que té propietats útils: .url per obtenir la URL pública, .name per al nom del fitxer i .path per la ruta absoluta al disc. Als templates, sempre cal comprovar si el camp té valor abans d'accedir-hi per evitar errors quan és opcional.

  • llibre.portada.url — retorna la URL completa per usar-la a <img src="...">. Combina MEDIA_URL amb la ruta relativa desada.
  • {% if llibre.portada %} — comprova que el camp tingui un fitxer associat abans de generar la URL, evitant errors en camps opcionals.
  • enctype="multipart/form-data" — atribut obligatori al <form> per enviar fitxers. Sense ell, Django no rep el fitxer.
  • request.FILES — diccionari on Django col·loca els fitxers pujats. Cal passar-lo al formulari: form = LlibreForm(request.POST, request.FILES).
Python cataleg/models.py + cataleg/views.py 
# ─── cataleg/models.py ───────────────────────────────────────
from django.db import models


def ruta_portada(instance, filename):
    """
    Genera una ruta organitzada per any i per ID de llibre.
    Ex: portades/2024/42/portada.jpg
    Evita col·lisions entre fitxers de diferents llibres.
    """
    ext = filename.rsplit('.', 1)[-1]
    return f'portades/{instance.pk}/portada.{ext}'


class Autor(models.Model):
    nom = models.CharField(max_length=150)
    cognoms = models.CharField(max_length=150)

    def __str__(self):
        return f'{self.nom} {self.cognoms}'


class Llibre(models.Model):
    titol = models.CharField(max_length=250)
    autor = models.ForeignKey(
        Autor,
        on_delete=models.CASCADE,
        related_name='llibres'
    )
    isbn = models.CharField(max_length=13, unique=True)
    any_publicacio = models.PositiveSmallIntegerField()

    # ImageField requereix Pillow: pip install Pillow
    # upload_to usa el callable definit a dalt
    portada = models.ImageField(
        upload_to=ruta_portada,
        blank=True,   # permet formularis sense portada
        null=True,    # permet NULL a la base de dades
        verbose_name='Portada del llibre',
    )

    class Meta:
        ordering = ['titol']
        verbose_name_plural = 'Llibres'

    def __str__(self):
        return self.titol


# ─── cataleg/views.py ────────────────────────────────────────
from django.shortcuts import render, get_object_or_404, redirect
from django.contrib.auth.decorators import login_required
from .models import Llibre
from .forms import LlibreForm


def detall_llibre(request, pk):
    """Mostra el detall d'un llibre, inclosa la portada."""
    llibre = get_object_or_404(Llibre, pk=pk)
    return render(request, 'cataleg/detall_llibre.html', {
        'llibre': llibre
    })


@login_required
def pujar_portada(request, pk):
    """Permet pujar o substituir la portada d'un llibre existent."""
    llibre = get_object_or_404(Llibre, pk=pk)

    if request.method == 'POST':
        form = LlibreForm(request.POST, request.FILES, instance=llibre)
        if form.is_valid():
            form.save()
            return redirect('cataleg:detall', pk=llibre.pk)
    else:
        form = LlibreForm(instance=llibre)

    return render(request, 'cataleg/pujar_portada.html', {
        'form': form,
        'llibre': llibre,
    })

PythonSolució completa
# forms.py
from django import forms
from .models import Autor
import os

class AutorForm(forms.ModelForm):
    class Meta:
        model = Autor
        fields = ['nom', 'biografia', 'foto']
        widgets = {
            'biografia': forms.Textarea(attrs={'rows': 4}),
        }

    def clean_foto(self):
        foto = self.cleaned_data.get('foto')
        if foto:
            # Validació de mida (màx 2 MB)
            mida_maxima = 2 * 1024 * 1024  # 2 MB en bytes
            if foto.size > mida_maxima:
                raise forms.ValidationError(
                    f"La imatge no pot superar 2 MB. Mida actual: {foto.size / 1024 / 1024:.1f} MB"
                )

            # Validació d'extensió
            extensio = os.path.splitext(foto.name)[1].lower()
            extensions_valides = ['.jpg', '.jpeg', '.png']
            if extensio not in extensions_valides:
                raise forms.ValidationError(
                    f"Format no acceptat '{extensio}'. Formats vàlids: {', '.join(extensions_valides)}"
                )

        return foto
