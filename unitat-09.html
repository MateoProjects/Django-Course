Tags i Filtres Personalitzats

Estén el sistema de templates de Django amb la teva pròpia lògica reutilitzable

En aquesta unitat aprendràs:

  • Crear l'estructura de carpetes templatetags/ correcta

◆ Estructura de templatetags/ i filtres bàsics

Quan Django no ofereix cap filtre o tag built-in que satisfaci una necessitat concreta, podem crear-ne de propis dins del directori templatetags/ de l'aplicació. Aquesta carpeta ha d'existir com a paquet Python, és a dir, ha de contenir un fitxer __init__.py buit. Django descobrirà els mòduls d'aquesta carpeta automàticament si l'aplicació és a INSTALLED_APPS.

Un filtre és una funció Python que rep un valor (i opcionalment un argument) i en retorna un altre valor transformat. Es registra amb el decorador @register.filter de la biblioteca django.template. Al template, el filtre s'aplica amb la barra vertical: {{ valor|nom_filtre }}. Si el filtre ha de retornar HTML que no volem que Django escapi, cal fer-ho passar per mark_safe() de django.utils.safestring.

  • books/templatetags/ — directori que Django reconeix com a mòdul de tags
  • __init__.py — fitxer buit que converteix la carpeta en paquet Python
  • books_tags.py — fitxer amb els nostres filtres i tags (el nom és lliure)
  • register = template.Library() — instància del registre de tags de Django
  • @register.filter — decora una funció per convertir-la en filtre de template
  • {% load books_tags %} — carrega el mòdul de tags al template (obligatori)
  • mark_safe(html) — marca una cadena com a HTML segur (no s'escapa)
⚠️ Atenció

Usa mark_safe() únicament amb cadenes que tu has construït o has netejat prèviament. Mai apliquis mark_safe() a contingut que prové directament de l'usuari, ja que obriria una vulnerabilitat XSS.

Python books/templatetags/books_tags.py 
from django import template
from django.utils.safestring import mark_safe

# Cal instanciar Library per poder registrar filtres i tags
register = template.Library()


@register.filter(name='disponible')
def disponible(exemplars_disponibles):
    """Retorna True si hi ha exemplars disponibles per prestar."""
    return exemplars_disponibles > 0


@register.filter(name='format_isbn')
def format_isbn(isbn):
    """
    Formata un ISBN de 13 dígits com: 978-84-376-0494-7
    Si l'ISBN no té 13 caràcters, el retorna sense modificar.
    """
    isbn = str(isbn).replace('-', '').replace(' ', '')
    if len(isbn) != 13:
        return isbn
    # Grup registre (3) + país (2) + editor (3) + títol (4) + dígit control (1)
    return f"{isbn[:3]}-{isbn[3:5]}-{isbn[5:8]}-{isbn[8:12]}-{isbn[12]}"


@register.filter(name='estat_badge')
def estat_badge(estat):
    """
    Rep l'estat d'un exemplar i retorna un badge HTML amb color.
    mark_safe() és segur aquí perquè construïm l'HTML nosaltres mateixos;
    l'estat ve del nostre model, no de l'entrada de l'usuari.
    """
    colors = {
        'disponible': '#2ECC71',
        'prestat':    '#F59E0B',
        'reservat':   '#4A9EFF',
        'baixa':      '#6B7280',
    }
    color = colors.get(estat, '#6B7280')
    html = (
        f'<span style="color:{color}; font-weight:600; '
        f'font-family:\'JetBrains Mono\',monospace; font-size:0.85em;">'
        f'{estat.capitalize()}</span>'
    )
    return mark_safe(html)

◆ simple_tag, inclusion_tag i accés al context

Els filtres transformen un valor en un altre, però de vegades necessitem lògica més complexa: consultar la base de dades, retornar múltiples valors o renderitzar un fragment de template. Per a aquests casos Django ofereix dos tipus de tags addicionals:

  • @register.simple_tag — pot retornar qualsevol valor Python (string, número, objecte, QuerySet). El resultat s'insereix directament al template o es pot guardar en una variable amb as nom_var.
  • @register.inclusion_tag('template.html') — executa la funció, rep un diccionari que s'usa com a context, i renderitza el template indicat. Ideal per a components reutilitzables (sidebar, widget de prestecs, etc.).
  • takes_context=True — paràmetre opcional que fa que el primer argument de la funció sigui el context complet del template pare. Permet accedir a variables com request o user.

La diferència clau entre simple_tag i inclusion_tag és que el primer retorna un valor simple (text o objecte) mentre que el segon renderitza tot un sub-template HTML. Usa inclusion_tag quan necessitin HTML estructurat (taules, llistes, components) i simple_tag per a valors o càlculs.

📌 Nota

Per accedir a request dins d'un tag, el context processor django.template.context_processors.request ha d'estar actiu a TEMPLATES['OPTIONS']['context_processors']. Sense ell, context['request'] no existirà.

Python books/templatetags/books_tags.py (continuació) 
from books.models import Prestec


@register.simple_tag
def total_prestecs_actius():
    """
    Retorna el nombre total de préstecs actius a tota la biblioteca.
    Es pot usar al template com: {% total_prestecs_actius %}
    o guardar en variable: {% total_prestecs_actius as n_actius %}
    """
    return Prestec.objects.filter(retornat=False).count()


@register.simple_tag(takes_context=True)
def prestecs_del_lector(context):
    """
    Retorna els préstecs actius de l'usuari actual.
    takes_context=True ens dóna accés al context del template pare,
    on hi ha 'request' gràcies al context processor corresponent.
    """
    request = context.get('request')
    if request and request.user.is_authenticated:
        return Prestec.objects.filter(
            lector__usuari=request.user,
            retornat=False
        ).select_related('llibre')
    return Prestec.objects.none()


@register.inclusion_tag('books/components/darrers_prestecs.html', takes_context=True)
def mostra_darrers_prestecs(context, limit=5):
    """
    Renderitza el component darrers_prestecs.html amb els últims préstecs.
    L'argument 'limit' es pot passar directament al template:
    {% mostra_darrers_prestecs limit=3 %}
    """
    request = context.get('request')
    if request and request.user.is_authenticated:
        prestecs = Prestec.objects.filter(
            lector__usuari=request.user
        ).select_related('llibre').order_by('-data_prestec')[:limit]
    else:
        prestecs = Prestec.objects.none()

    # El diccionari retornat és el context del sub-template
    return {
        'prestecs': prestecs,
        'limit': limit,
    }
HTML books/templates/books/components/darrers_prestecs.html 
{% load books_tags %}
{# Sub-template renderitzat per l'inclusion_tag mostra_darrers_prestecs #}
<div class="darrers-prestecs">
  <h4>Darrers préstecs ({{ limit }}):</h4>
  {% if prestecs %}
    <ul>
      {% for prestec in prestecs %}
      <li>
        {{ prestec.llibre.titol }}
        — {{ prestec.data_prestec|date:"d/m/Y" }}
        {% if prestec.retornat %}
          <span style="color:#2ECC71">✓ Retornat</span>
        {% else %}
          <span style="color:#F59E0B">Pendent</span>
        {% endif %}
      </li>
      {% endfor %}
    </ul>
  {% else %}
    <p>No tens préstecs recents.</p>
  {% endif %}
</div>
🔮 Avançat

Pots registrar un filtre amb nom diferent al de la funció usant @register.filter(name='nom_custom'). Si no especifiques nom, Django usa el nom de la funció Python. Pots tenir múltiples fitxers dins de templatetags/ i cada un s'ha de carregar per separat amb {% load %}.

# books/templatetags/books_tags.py
from django import template
from django.utils.html import format_html
from django.utils import timezone

register = template.Library()

@register.filter(name='estat_prestec')
def estat_prestec(prestec):
    """Retorna un badge HTML amb l'estat del préstec."""
    avui = timezone.now().date()
    if prestec.estat == 'retornat':
        color = '#057A55'
        bg = '#ECFDF5'
        text = 'Retornat'
    elif prestec.data_retorn_prevista < avui:
        color = '#DC2626'
        bg = '#FEF2F2'
        text = 'Vençut'
    else:
        color = '#92530A'
        bg = '#FEF9E7'
        text = 'Actiu'
    return format_html(
        '<span style="color:{};background:{};padding:2px 8px;border-radius:4px;font-size:0.85em;">{}</span>',
        color, bg, text
    )

# Ús al template:
