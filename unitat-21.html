Management Commands

Crea comandes personalitzades per a manage.py: importa dades, neteja registres i automatitza tasques de manteniment des de la línia d'ordres.

En aquesta unitat aprendràs:

  • L'estructura de directoris i el fitxer Python d'una management command
  • Heretar de BaseCommand i implementar el mètode handle()
  • Escriure sortida amb self.stdout.write() i els estils de color
  • Acceptar arguments i opcions amb add_arguments()
  • Invocar comandes des de codi Python amb call_command()
  • Casos d'ús reals: importar CSV, netejar dades antigues, generar fixtures

◆ Estructura d'una management command

Les management commands de Django són scripts Python que s'invoquen a través de manage.py. Permeten executar lògica de negoci directament des de la línia d'ordres o des de tasques programades (cron, Celery beat) sense necessitat d'una petició HTTP. Django ja n'inclou moltes: migrate, createsuperuser, collectstatic. La teva app en pot afegir tantes com necessitis.

El nom del fitxer Python dins de commands/ és exactament el nom que usaràs a manage.py. Per invocar importar_llibres.py faràs: python manage.py importar_llibres.

La classe Command

  • class Command(BaseCommand) — herència obligatòria. Django la descobreix automàticament si el fitxer és a la carpeta correcta.
  • help — atribut de classe amb la descripció de la command. Apareix a python manage.py help importar_llibres.
  • handle(self, *args, **options) — mètode principal. Tot el que vols que faci la command va aquí. Rep els arguments processats a options.
  • self.stdout.write(text) — escriu a la sortida estàndard. Preferible a print() perquè es pot capturar i provar.
  • self.style.SUCCESS('OK') — aplica color verd al text. Altres: self.style.ERROR() (vermell), self.style.WARNING() (groc).
  • self.stderr.write(text) — escriu a stderr per a missatges d'error que no han d'anar a stdout.
  • options['verbosity'] — nivell de verbositat (0=silenciós, 1=normal, 2=detallat, 3=molt detallat). Django el passa automàticament.
💡 Bones pràctiques

Una management command és codi Python normal. Pots importar models, fer consultes ORM, enviar emails, cridar APIs externes. El secret és mantenir la lògica de negoci als models o serveis i fer que la command sigui tan fina com sigui possible: llegir arguments → cridar servei → informar del resultat.

Python cataleg/management/commands/importar_llibres.py 
"""
Command per importar llibres des d'un fitxer CSV.

Ús:
    python manage.py importar_llibres fitxers/llibres.csv
    python manage.py importar_llibres fitxers/llibres.csv --dry-run
    python manage.py importar_llibres fitxers/llibres.csv --limit 50
"""
import csv
from pathlib import Path
from django.core.management.base import BaseCommand, CommandError
from cataleg.models import Autor, Llibre


class Command(BaseCommand):
    help = 'Importa llibres des d\'un fitxer CSV al catàleg de bibliapp'

    def add_arguments(self, parser):
        # Argument posicional obligatori: ruta al fitxer CSV
        parser.add_argument(
            'fitxer_csv',
            type=str,
            help='Ruta al fitxer CSV amb els llibres a importar',
        )
        # Opció de simulació: mostra el que faria sense desar res
        parser.add_argument(
            '--dry-run',
            action='store_true',
            default=False,
            help='Simula la importació sense escriure a la base de dades',
        )
        # Opció per limitar el nombre de registres processats
        parser.add_argument(
            '--limit',
            type=int,
            default=None,
            help='Màxim de llibres a importar (per defecte: tots)',
        )

    def handle(self, *args, **options):
        fitxer = Path(options['fitxer_csv'])
        dry_run = options['dry_run']
        limit = options['limit']
        verbosity = options['verbosity']

        # Validació prèvia: el fitxer ha d'existir
        if not fitxer.exists():
            raise CommandError(f'El fitxer "{fitxer}" no existeix.')

        if dry_run:
            self.stdout.write(
                self.style.WARNING('Mode simulació actiu — no es desaran dades')
            )

        creats = 0
        errors = 0

        with open(fitxer, newline='', encoding='utf-8') as f:
            reader = csv.DictReader(f)

            for i, fila in enumerate(reader):
                if limit and i >= limit:
                    break

                try:
                    # Obtenir o crear l'autor per nom complet
                    autor, _ = Autor.objects.get_or_create(
                        nom=fila['autor_nom'],
                        cognoms=fila['autor_cognoms'],
                    )

                    if not dry_run:
                        Llibre.objects.get_or_create(
                            isbn=fila['isbn'],
                            defaults={
                                'titol': fila['titol'],
                                'autor': autor,
                                'any_publicacio': int(fila['any']),
                            },
                        )
                    creats += 1

                    # Mostrar detall només si verbosity és alt
                    if verbosity >= 2:
                        self.stdout.write(f'  → "{fila["titol"]}" ({fila["isbn"]})')

                except KeyError as e:
                    errors += 1
                    self.stderr.write(
                        self.style.ERROR(f'Columna mancant a la fila {i+1}: {e}')
                    )

        # Resum final
        prefix = '[SIMULACIÓ] ' if dry_run else ''
        self.stdout.write(
            self.style.SUCCESS(
                f'{prefix}Importació completada: {creats} llibres, {errors} errors'
            )
        )

◆ Arguments, opcions i call_command()

El mètode add_arguments() rep un ArgumentParser de la biblioteca estàndard argparse. Pots afegir arguments posicionals i opcionals amb tota la potència d'argparse: tipus, valors per defecte, ajuda, múltiples valors, etc. Django afegeix automàticament les opcions --verbosity, --settings, --pythonpath i --traceback.

  • parser.add_argument('nom') — argument posicional. Ha d'aparèixer sense prefixe a la línia d'ordres.
  • parser.add_argument('--opcio') — opció opcional. Al diccionari options arriba com options['opcio'] (les guions es converteixen en guions baixos).
  • action='store_true' — l'opció és un booleà. Si apareix a la comanda, options['dry_run'] és True.
  • nargs='+' — l'argument accepta un o més valors. Es rep com a llista.
  • choices=['json', 'csv'] — limita els valors acceptats. Django valida i mostra error si el valor no és a la llista.

call_command() — invocar des de Python

call_command() permet executar qualsevol management command des de codi Python: en tests, en altres commands o en scripts d'inicialització. És especialment útil per encadenar comandes o per invocar-les en el context de proves.

  • call_command('importar_llibres', 'fitxer.csv') — arguments posicionals com a strings.
  • call_command('importar_llibres', 'fitxer.csv', dry_run=True, limit=10) — opcions com a arguments de paraula clau Python.
  • call_command('migrate') — pots cridar commands internes de Django com migrate o collectstatic.
  • En tests, call_command facilita provar la lògica de la command sense usar subprocess.
📌 Casos d'ús habituals

Les management commands brillen en tasques de manteniment programades: importar dades de fonts externes cada nit, enviar resums per correu electrònic cada dilluns, eliminar registres obsolets, re-indexar un motor de cerca, o pre-escalfar la cache. Configura-les al crontab del servidor o a Celery Beat.

Python cataleg/management/commands/netejar_prestecs.py 
"""
Command per eliminar préstecs antics tancats.

Ús:
    python manage.py netejar_prestecs
    python manage.py netejar_prestecs --anys 1
    python manage.py netejar_prestecs --dry-run

Cron (exemple): 0 3 1 * * python manage.py netejar_prestecs
"""
from datetime import date
from dateutil.relativedelta import relativedelta
from django.core.management.base import BaseCommand
from django.utils import timezone
from prestecs.models import Prestec


class Command(BaseCommand):
    help = 'Elimina préstecs tancats amb més de N anys d\'antiguitat'

    def add_arguments(self, parser):
        parser.add_argument(
            '--anys',
            type=int,
            default=2,
            help='Elimina préstecs tancats fa més d\'aquest nombre d\'anys (per defecte: 2)',
        )
        parser.add_argument(
            '--dry-run',
            action='store_true',
            help='Mostra quants registres s\'eliminaran sense esborrar-los',
        )
        parser.add_argument(
            '--no-confirmacio',
            action='store_true',
            help='Ometre la pregunta de confirmació (útil per a cron)',
        )

    def handle(self, *args, **options):
        anys = options['anys']
        dry_run = options['dry_run']
        no_confirmacio = options['no_confirmacio']

        # Calcular la data límit
        data_limit = timezone.now() - relativedelta(years=anys)

        # Préstecs tancats (data_retorn != null) anteriors al límit
        prestecs_antics = Prestec.objects.filter(
            data_retorn__isnull=False,
            data_retorn__lt=data_limit,
        )
        total = prestecs_antics.count()

        self.stdout.write(
            f'Préstecs tancats fa més de {anys} anys: '
            f'{self.style.WARNING(str(total))} registres'
        )

        if total == 0:
            self.stdout.write(self.style.SUCCESS('Res a eliminar.'))
            return

        if dry_run:
            self.stdout.write(
                self.style.WARNING('[SIMULACIÓ] No s\'ha eliminat cap registre.')
            )
            return

        # Demanar confirmació si no s'ha passat --no-confirmacio
        if not no_confirmacio:
            resposta = input(
                f'Segur que vols eliminar {total} préstecs? [s/N] '
            )
            if resposta.lower() not in ('s', 'si', 'sí', 'y', 'yes'):
                self.stdout.write('Operació cancel·lada.')
                return

        # Eliminació en bloc (eficient per a molts registres)
        esborrats, _ = prestecs_antics.delete()
        self.stdout.write(
            self.style.SUCCESS(f'Eliminats {esborrats} préstecs antics correctament.')
        )

⚠️ Atenció amb .delete()

L'eliminació massiva amb QuerySet.delete() no dispara els signals pre_delete i post_delete de cada objecte individual. Si tens signals importants (p. ex. eliminar fitxers del disc en esborrar un model), usa un bucle for obj in qs: obj.delete() en lloc de qs.delete().

from django.core.management.base import BaseCommand
from django.db.models import Count, Avg
from biblioteca.models import Llibre, Autor, Prestec

class Command(BaseCommand):
    help = 'Genera estadístiques de la biblioteca'

    def add_arguments(self, parser):
        parser.add_argument(
            '--format',
            choices=['text', 'csv'],
            default='text',
            help='Format de sortida (text o csv)'
        )

    def handle(self, *args, **options):
        format_sortida = options['format']

        total_llibres = Llibre.objects.count()
        total_autors = Autor.objects.count()
        llibres_disponibles = Llibre.objects.filter(disponible=True).count()

        autor_mes_llibres = (
            Autor.objects.annotate(num_llibres=Count('llibres'))
            .order_by('-num_llibres')
            .first()
        )

        if format_sortida == 'csv':
            self.stdout.write('Mètrica,Valor')
            self.stdout.write(f'Total llibres,{total_llibres}')
            self.stdout.write(f'Total autors,{total_autors}')
            self.stdout.write(f'Llibres disponibles,{llibres_disponibles}')
            if autor_mes_llibres:
                self.stdout.write(f'Autor més prolífic,{autor_mes_llibres.nom}')
        else:
            self.stdout.write(self.style.SUCCESS('=== Estadístiques de la Biblioteca ==='))
            self.stdout.write(f'Total de llibres: {total_llibres}')
            self.stdout.write(f'Total d\'autors: {total_autors}')
            self.stdout.write(f'Llibres disponibles: {llibres_disponibles}')
            self.stdout.write(
                f'Llibres no disponibles: {total_llibres - llibres_disponibles}'
            )
            if autor_mes_llibres:
                self.stdout.write(
                    f'Autor més prolífic: {autor_mes_llibres.nom} '
                    f'({autor_mes_llibres.num_llibres} llibres)'
                )
            self.stdout.write(self.style.SUCCESS('Fet!'))

# biblioteca/management/commands/importar_llibres.py
import csv
import os
from django.core.management.base import BaseCommand, CommandError
from biblioteca.models import Llibre, Autor

class Command(BaseCommand):
    help = 'Importa llibres des d\'un fitxer CSV'

    def add_arguments(self, parser):
        parser.add_argument('fitxer_csv', type=str, help='Ruta al fitxer CSV')

    def handle(self, *args, **options):
        ruta = options['fitxer_csv']

        if not os.path.exists(ruta):
            raise CommandError(f'El fitxer no existeix: {ruta}')

        creats = 0
        omesos = 0
        errors = 0

        with open(ruta, newline='', encoding='utf-8') as f:
            reader = csv.DictReader(f)

            for num_fila, fila in enumerate(reader, start=2):
                try:
                    nom_autor = fila['autor'].strip()
                    titol = fila['titol'].strip()
                    any_pub = int(fila['any_publicacio'].strip())

                    autor, _ = Autor.objects.get_or_create(nom=nom_autor)

                    _, creat = Llibre.objects.get_or_create(
                        titol=titol,
                        autor=autor,
                        defaults={'any_publicacio': any_pub}
                    )

                    if creat:
                        creats += 1
                        self.stdout.write(f'  ✓ Creat: {titol} ({nom_autor})')
                    else:
                        omesos += 1
                        self.stdout.write(
                            self.style.WARNING(f'  ~ Omès (ja existeix): {titol}')
                        )
                except (KeyError, ValueError) as e:
                    errors += 1
                    self.stdout.write(
                        self.style.ERROR(f'  ✗ Error a la fila {num_fila}: {e}')
                    )

        self.stdout.write(self.style.SUCCESS(
            f'\nResum: {creats} creats, {omesos} omesos, {errors} errors'
        ))
