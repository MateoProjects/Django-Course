Formularis (Forms i ModelForms)

Valida, processa i desa dades d'usuari de manera segura i reutilitzable

En aquesta unitat aprendràs:

  • Distingir entre forms.Form i forms.ModelForm i quan usar cadascun
  • Definir camps, widgets i atributs de formulari de forma declarativa
  • Implementar validació per camp (clean_<field>) i validació global (clean())
  • Usar is_valid(), cleaned_data i save() a les vistes

◆ Form vs ModelForm — camps, widgets i atributs

Django ofereix dues classes base per a formularis: forms.Form per a formularis independents del model (cercadors, formularis de contacte, filtres), i forms.ModelForm per a formularis vinculats a un model Django. Un ModelForm genera automàticament els camps a partir dels camps del model, estalviant codi repetitiu, i el mètode save() crea o actualitza l'objecte del model directament. Amb Form tens control total però has de gestionar manualment la creació d'objectes.

Característica forms.Form forms.ModelForm
Camps generats automàticament No — els defineixes tu Sí — des del model
Mètode save() No disponible Sí — crea/actualitza objecte
Vinculació amb model Cap Via Meta.model
Cas d'ús típic Cerca, contacte, filtres Crear/editar registres

Cada camp de formulari té atributs que controlen el seu comportament i com es mostra. Els widgets determinen l'element HTML que es genera, mentre que els atributs com label, help_text, required o initial controlen la seva presentació i comportament.

  • CharField(max_length=100) — camp de text curt, genera <input type="text">
  • EmailField() — valida que el valor sigui un email vàlid
  • IntegerField(min_value=0) — camp numèric enter amb validació de rang
  • DateField(widget=DateInput(type='date')) — data amb selector HTML5
  • ChoiceField(choices=CHOICES) — llista desplegable de valors predefinits
  • BooleanField(required=False) — casella de selecció (checkbox)
  • widget=Textarea(attrs={'rows': 4}) — widget amb atributs HTML personalitzats
  • label='Etiqueta visible' — text que es mostra davant del camp
  • help_text='Instrucció addicional' — text d'ajuda sota el camp
  • initial=date.today — valor inicial (pot ser un callable)
📌 Nota

En un ModelForm, pots excloure camps amb Meta.exclude = ['camp'] o indicar exactament quins camps vols amb Meta.fields = ['camp1', 'camp2']. Usa sempre fields en lloc d'exclude per seguretat: un exclude podria exposar camps nous afegits al model en el futur.

Python books/forms.py — PrestecForm (ModelForm) 
from django import forms
from django.utils import timezone
from books.models import Prestec, Lector


class PrestecForm(forms.ModelForm):
    """
    Formulari per crear un nou préstec.
    ModelForm genera automàticament els camps des del model Prestec,
    però limitem quins camps apareixen amb Meta.fields.
    """

    class Meta:
        model = Prestec
        fields = ['lector', 'llibre', 'data_prestec', 'data_retorn_prevista']
        widgets = {
            # DateInput amb type='date' activa el selector de dates natiu del navegador
            'data_prestec': forms.DateInput(
                attrs={'type': 'date'},
                format='%Y-%m-%d',
            ),
            'data_retorn_prevista': forms.DateInput(
                attrs={'type': 'date'},
                format='%Y-%m-%d',
            ),
        }
        labels = {
            'lector': 'Lector',
            'llibre': 'Llibre',
            'data_prestec': 'Data del préstec',
            'data_retorn_prevista': 'Data de retorn prevista',
        }
        help_texts = {
            'data_retorn_prevista': 'Ha de ser posterior a la data del préstec.',
        }

    def __init__(self, *args, **kwargs):
        """
        Personalitzem el formulari a l'inicialitzar-lo:
        - Preomplim la data de préstec amb avui
        - Filtrem els lectors actius
        """
        super().__init__(*args, **kwargs)
        # Valor inicial per defecte: avui
        self.fields['data_prestec'].initial = timezone.now().date()
        # Limitem els lectors al desplegable: nomes actius
        self.fields['lector'].queryset = Lector.objects.filter(actiu=True)

    def clean_data_prestec(self):
        """
        Validació per al camp 'data_prestec':
        No permetem préstecs amb data futura (error d'introducció de dades).
        """
        data = self.cleaned_data['data_prestec']
        if data > timezone.now().date():
            raise forms.ValidationError(
                "La data del préstec no pot ser futura."
            )
        return data

    def clean(self):
        """
        Validació global (accés a múltiples camps a la vegada).
        S'executa després de les validacions individuals de cada camp.
        """
        cleaned = super().clean()
        data_prestec = cleaned.get('data_prestec')
        data_retorn  = cleaned.get('data_retorn_prevista')

        # Comprova que la data de retorn sigui posterior a la de préstec
        if data_prestec and data_retorn:
            if data_retorn <= data_prestec:
                raise forms.ValidationError(
                    "La data de retorn ha de ser posterior a la data del préstec."
                )
        return cleaned

◆ Validació, cleaned_data i integració a la vista

El cicle de vida d'un formulari Django té dues fases: la fase bound (lligat a dades, quan l'usuari ha enviat el formulari) i la fase unbound (buit, per mostrar el formulari per primera vegada). La validació s'activa quan cridem form.is_valid(), que executa internament tot el pipeline de validació en aquest ordre:

  • is_valid() — activa la validació completa i retorna True/False
  • to_python() — converteix el valor cru (string) al tipus Python del camp
  • validate() — aplica els validators del camp (built-in i personalitzats)
  • clean_<nom_camp>() — validació específica per a un camp concret; rep i retorna el valor ja convertit
  • clean() — validació creuada entre camps; rep i retorna cleaned_data sencer
  • form.cleaned_data — diccionari amb tots els valors validats i convertits (disponible si is_valid() és True)
  • form.errors — diccionari d'errors per camp (disponible si is_valid() és False)
  • form.save() — (només ModelForm) crea o actualitza l'objecte del model
  • form.save(commit=False) — crea l'objecte però no el desa; permet modificar-lo abans de .save()
⚠️ Atenció

Dins de clean_<camp>() sempre retorna el valor (return data), encara que no l'hagis modificat. Si no retornes res, el camp quedarà com None a cleaned_data, cosa que pot causar errors inesperats a la validació global.

Python books/forms.py — CercaLlibreForm (Form pur) 
class CercaLlibreForm(forms.Form):
    """
    Formulari de cerca de llibres (Form pur, no lligat a cap model).
    Permet filtrar per títol, autor i rang d'anys de publicació.
    """
    titol = forms.CharField(
        required=False,
        label='Títol',
        widget=forms.TextInput(attrs={'placeholder': 'Cerca per títol...'}),
    )
    autor = forms.CharField(
        required=False,
        label='Autor',
    )
    any_des_de = forms.IntegerField(
        required=False,
        label='Any des de',
        min_value=1000,
        max_value=2100,
        widget=forms.NumberInput(attrs={'placeholder': '1900'}),
    )
    any_fins_a = forms.IntegerField(
        required=False,
        label='Any fins a',
        min_value=1000,
        max_value=2100,
        widget=forms.NumberInput(attrs={'placeholder': '2024'}),
    )
    nomes_disponibles = forms.BooleanField(
        required=False,
        label='Mostrar només disponibles',
        initial=False,
    )

    def clean(self):
        """
        Validació global: si s'especifiquen els dos anys, el rang ha de ser vàlid.
        """
        cleaned = super().clean()
        any_des_de = cleaned.get('any_des_de')
        any_fins_a = cleaned.get('any_fins_a')

        if any_des_de and any_fins_a and any_des_de > any_fins_a:
            raise forms.ValidationError(
                "L'any inicial no pot ser posterior a l'any final del rang."
            )

        # Si no s'ha introduït cap criteri de cerca, informem l'usuari
        criteris = [cleaned.get('titol'), cleaned.get('autor'), any_des_de, any_fins_a]
        if not any(criteris):
            raise forms.ValidationError(
                "Introdueix almenys un criteri de cerca."
            )

        return cleaned
Python books/views.py — vista amb PrestecForm 
from django.shortcuts import render, redirect
from django.contrib.auth.decorators import login_required
from django.contrib import messages
from books.forms import PrestecForm


@login_required
def nou_prestec(request):
    """
    Vista per crear un nou préstec.
    GET: mostra el formulari buit (unbound)
    POST: valida i desa, o torna a mostrar amb errors
    """
    if request.method == 'POST':
        # Formulari lligat a les dades POST (bound form)
        form = PrestecForm(request.POST)
        if form.is_valid():
            # save(commit=False) ens dona l'objecte sense desar-lo,
            # per poder afegir camps addicionals (com qui ha creat el registre)
            prestec = form.save(commit=False)
            prestec.creat_per = request.user
            prestec.save()
            messages.success(request, f"Préstec creat correctament per a {prestec.lector}.")
            return redirect('books:prestec_detall', pk=prestec.pk)
        # Si és invàlid, el formulari conté errors que es mostren al template
    else:
        # GET: formulari buit (unbound form)
        form = PrestecForm()

    return render(request, 'books/nou_prestec.html', {'form': form})

🔮 Avançat

Pots usar {{ form.as_p }}, {{ form.as_table }} o {{ form.as_div }} per renderitzar tots els camps automàticament. Per a un control total del disseny, renderitza cada camp individualment com a l'exemple de dalt: {{ field }} per al widget i {{ field.label_tag }} per a l'etiqueta.

# books/forms.py
from django import forms
from django.utils import timezone
from .models import Llibre, Prestec, Lector

class LlibreForm(forms.ModelForm):
    class Meta:
        model = Llibre
        fields = ['titol', 'autor', 'isbn', 'any_publicacio', 'genere', 'num_pagines', 'descripcio']
        widgets = {
            'any_publicacio': forms.NumberInput(attrs={'min': 1000, 'max': timezone.now().year}),
            'descripcio': forms.Textarea(attrs={'rows': 4}),
        }

    def clean_any_publicacio(self):
        any_pub = self.cleaned_data.get('any_publicacio')
        any_actual = timezone.now().year
        if any_pub and any_pub > any_actual:
            raise forms.ValidationError(
                f"L'any de publicació no pot ser futur. Any actual: {any_actual}."
            )
        return any_pub


class PrestecForm(forms.ModelForm):
    class Meta:
        model = Prestec
        fields = ['data_retorn_prevista', 'notes']
        widgets = {
            'data_retorn_prevista': forms.DateInput(attrs={'type': 'date'}),
            'notes': forms.Textarea(attrs={'rows': 3, 'placeholder': 'Notes opcionals...'}),
        }

    def __init__(self, *args, lector=None, **kwargs):
        self.lector = lector
        super().__init__(*args, **kwargs)

    def clean_data_retorn_prevista(self):
        data = self.cleaned_data.get('data_retorn_prevista')
        avui = timezone.now().date()
        if data and data <= avui:
            raise forms.ValidationError("La data de retorn ha de ser posterior a avui.")
        if data and (data - avui).days > 30:
            raise forms.ValidationError("El préstec no pot superar 30 dies.")
        return data

    def clean(self):
        cleaned = super().clean()
        if self.lector:
            prestecs_actius = Prestec.objects.filter(
                lector=self.lector, estat='actiu'
            ).count()
            if prestecs_actius >= 3:
                raise forms.ValidationError(
                    "No es poden tenir més de 3 préstecs actius simultàniament."
                )
        return cleaned

# books/forms.py
from .models import Llibre

GENERE_CHOICES_CERCA = [('', 'Tots els gèneres')] + Llibre.GENERE_CHOICES

class CercaLlibreForm(forms.Form):
    text = forms.CharField(required=False, label='Cerca',
        widget=forms.TextInput(attrs={'placeholder': 'Títol o autor...'}))
    genere = forms.ChoiceField(choices=GENERE_CHOICES_CERCA, required=False)
    nomes_disponibles = forms.BooleanField(required=False, label='Només disponibles')

# books/views.py
from django.db.models import Q

def llistar_llibres(request):
    form = CercaLlibreForm(request.GET)
    qs = Llibre.objects.select_related('autor')
    if form.is_valid():
        text = form.cleaned_data.get('text')
        genere = form.cleaned_data.get('genere')
        nomes_disp = form.cleaned_data.get('nomes_disponibles')
        if text:
            qs = qs.filter(Q(titol__icontains=text) | Q(autor__cognoms__icontains=text))
        if genere:
            qs = qs.filter(genere=genere)
        if nomes_disp:
            qs = qs.filter(disponible=True)
    return render(request, 'books/llistar_llibres.html', {'form': form, 'llibres': qs})

◆ Resum

Tipus de formulari

  • forms.Form → lliure
  • forms.ModelForm → lligat a model
  • ModelForm.save() → crea/actualitza

Cicle de validació

  • form.is_valid()
  • clean_<camp>() per camp
  • clean() per creuaments
  • form.cleaned_data

Widgets comuns

  • TextInput, Textarea
  • DateInput(type='date')
  • Select, CheckboxInput
  • NumberInput

A la vista (POST)

  • form = Form(request.POST)
  • if form.is_valid():
  • obj = form.save()
  • return redirect(...)
