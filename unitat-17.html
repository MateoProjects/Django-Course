Django REST Framework

Construeix APIs RESTful professionals amb serialitzadors, viewsets i autenticació basada en tokens

En aquesta unitat aprendràs:

  • Configurar DRF i entendre la diferència entre Serializer i ModelSerializer
  • Crear ViewSets i routers per exposar recursos REST amb mínim codi
  • Protegir endpoints amb permissions personalitzades i classes d'autenticació
  • Afegir accions addicionals amb @action i documentar la API amb Swagger

◆ Instal·lació, configuració i Serialitzadors

Django REST Framework (DRF) és la biblioteca estàndard per construir APIs REST amb Django. S'instal·la com qualsevol paquet pip i es registra a INSTALLED_APPS. La configuració global es fa a través del diccionari REST_FRAMEWORK al fitxer de settings, on es defineixen les classes per defecte de renderitzadors, permisos i autenticació.

Shell instal·lació 
pip install djangorestframework drf-yasg

Un cop instal·lat, cal afegir 'rest_framework' i 'drf_yasg' a INSTALLED_APPS i configurar les opcions globals. El bloc REST_FRAMEWORK controla el comportament per defecte de tota la API:

  • DEFAULT_RENDERER_CLASSES — formats de resposta (JSON és el predeterminat; BrowsableAPIRenderer afegeix la interfície web navegable)
  • DEFAULT_PERMISSION_CLASSES — qui pot accedir als endpoints per defecte (p. ex. IsAuthenticated per requerir login a tot arreu)
  • DEFAULT_AUTHENTICATION_CLASSES — com s'identifiquen els usuaris (sessions Django, tokens, JWT)
  • DEFAULT_PAGINATION_CLASS — paginació automàtica de llistes (PageNumberPagination)
  • PAGE_SIZE — quants elements per pàgina retorna la API per defecte

Els serialitzadors fan la feina de convertir objectes Python (instàncies de models Django) en dades primitives (JSON) i viceversa. Hi ha dues classes principals:

Classe Quan usar-la Diferència clau
Serializer Estructures personalitzades, no lligades a un model Cal declarar tots els camps manualment
ModelSerializer La majoria de casos: un model → un serialitzador Genera camps i validadors automàticament des del model

Dins d'un ModelSerializer, el bloc Meta és obligatori i especifica el model i els camps a exposar. Amb fields = '__all__' s'exposen tots els camps, però a la pràctica és millor llistar-los explícitament per evitar exposar dades sensibles accidentalment. SerializerMethodField permet afegir camps calculats que no existeixen al model:

  • read_only_fields — camps que la API retorna però que els clients no poden modificar (p. ex. creat_a, id)
  • SerializerMethodField — camp de només lectura que crida un mètode get_<nom_camp> per calcular el valor
  • validate_<camp> — mètode de validació a nivell de camp individual
  • validate — mètode de validació a nivell de l'objecte complet (per validacions entre camps)
  • to_representation — sobreescriviu-lo per personalitzar completament la sortida JSON d'un objecte
⚠️ Atenció

Mai useu fields = '__all__' en producció sense revisar primer quins camps exposa el model. Camps com password, claus d'API o dades personals s'exposarien per defecte. Sempre listeu els camps explícitament.

# bibliapp/api/serializers.py
from rest_framework import serializers
from biblioteca.models import Llibre, Autor, Prestec


class AutorSerializer(serializers.ModelSerializer):
    """Serialitzador bàsic per a Autor — usat com a camp imbricat."""
    class Meta:
        model = Autor
        fields = ['id', 'nom', 'cognom']


class LlibreSerializer(serializers.ModelSerializer):
    # Camp calculat: nom complet de l'autor sense exposar tota la relació
    autor_nom = serializers.SerializerMethodField()

    # Autor imbricat en lectura; només s'envia autor_id en escriptura
    autor = AutorSerializer(read_only=True)
    autor_id = serializers.PrimaryKeyRelatedField(
        queryset=Autor.objects.all(),
        source='autor',
        write_only=True
    )

    class Meta:
        model = Llibre
        fields = [
            'id', 'titol', 'isbn', 'any_publicacio',
            'disponible', 'autor', 'autor_id', 'autor_nom'
        ]
        read_only_fields = ['id', 'disponible']  # el client no toca aquests camps

    def get_autor_nom(self, obj):
        """Retorna 'Nom Cognom' de l'autor — camp calculat."""
        return f"{obj.autor.nom} {obj.autor.cognom}"

    def validate_isbn(self, value):
        """Valida que l'ISBN tingui exactament 13 digits."""
        digits = value.replace('-', '').replace(' ', '')
        if not digits.isdigit() or len(digits) != 13:
            raise serializers.ValidationError(
                "L'ISBN ha de tenir exactament 13 digits numèrics."
            )
        return digits  # guardem sempre en format net

    def validate(self, data):
        """Validació cross-camp: no es pot publicar un llibre futur."""
        from datetime import date
        if data.get('any_publicacio') and data['any_publicacio'] > date.today().year:
            raise serializers.ValidationError(
                "L'any de publicació no pot ser futur."
            )
        return data


class PrestecSerializer(serializers.ModelSerializer):
    # En resposta mostrem el títol del llibre; en petició enviem llibre_id
    llibre_titol = serializers.SerializerMethodField()
    lector_username = serializers.SerializerMethodField()

    class Meta:
        model = Prestec
        fields = [
            'id', 'llibre', 'lector', 'data_inici',
            'data_fi_prevista', 'data_retorn', 'actiu',
            'llibre_titol', 'lector_username'
        ]
        read_only_fields = ['id', 'data_retorn', 'actiu']

    def get_llibre_titol(self, obj):
        return obj.llibre.titol

    def get_lector_username(self, obj):
        return obj.lector.username

    def to_representation(self, instance):
        """Afegim l'estat del préstec a la representació JSON."""
        data = super().to_representation(instance)
        data['estat'] = 'retornat' if instance.data_retorn else 'actiu'
        return data

◆ ViewSets, Routers, Permissions i @action

DRF ofereix tres maneres d'escriure vistes d'API, de menys a més abstracció. APIView és la base: similar a una vista FBV però amb gestió de mètodes HTTP, negociació de contingut i respostes DRF. ViewSet agrupa les operacions d'un recurs (llistar, crear, recuperar, actualitzar, esborrar) en una sola classe. ModelViewSet implementa automàticament totes les operacions CRUD per a un model Django.

Classe Operacions incloses Quan usar
APIView Cap (cal definir get, post...) Endpoints molt personalitzats
ViewSet Cal definir list, retrieve... Lògica no estàndard però agrupada
ModelViewSet CRUD complet automàtic La majoria de recursos REST

El Router (normalment DefaultRouter) genera automàticament totes les URLs d'un ViewSet: /api/llibres/ per a llistar i crear, i /api/llibres/{id}/ per a detall, actualitzar i esborrar. Estalvia escriure patrons URL manualment.

Les permissions controlen qui pot fer cada operació. DRF inclou IsAuthenticated (usuari identificat), IsAdminUser (staff de Django), AllowAny i IsAuthenticatedOrReadOnly. Per a lògica personalitzada, es crea una classe que hereti de BasePermission i s'implementa has_permission (a nivell de vista) i/o has_object_permission (a nivell d'objecte individual).

  • permission_classes — llista de classes de permís aplicades a la vista; s'apliquen totes (AND lògic)
  • authentication_classes — com identifica el sistema l'usuari de la petició
  • @action(detail=True, methods=['post']) — defineix un endpoint addicional sobre un recurs concret (p. ex. /api/prestecs/5/retornar/)
  • @action(detail=False) — acció sobre la col·lecció (p. ex. /api/llibres/disponibles/)
  • get_queryset — sobreescriviu-lo per filtrar automàticament per usuari, paràmetres GET, etc.
  • get_serializer_class — retorna serialitzadors diferents per a operacions de lectura i escriptura
🔮 Nota avançada

drf-yasg genera documentació Swagger/OpenAPI automàticament a partir dels ViewSets i serialitzadors. Afegiu les URLs de get_swagger_view i get_schema_view al fitxer d'URLs principal. En producció, protegiu la documentació amb permission_classes=[IsAdminUser] per no exposar l'estructura de la API públicament.

📌 Bones pràctiques

Sobreescriviu perform_create i perform_update als ViewSets per injectar dades automàticament (com l'usuari autenticat) sense exposar-les com a camps editables pel client. Per exemple, serializer.save(lector=self.request.user) en un perform_create de PrestecViewSet.

Python bibliapp/api/views.py + permissions.py + urls.py 
# bibliapp/api/permissions.py
from rest_framework.permissions import BasePermission


class EsPropietariDelPrestec(BasePermission):
    """
    Permís personalitzat: permet modificar un préstec
    només si l'usuari autenticat és el lector que el va crear.
    Adminstradors ho poden fer sempre.
    """
    message = "Només el lector propietari pot modificar aquest préstec."

    def has_object_permission(self, request, view, obj):
        # Admins sempre tenen accés
        if request.user.is_staff:
            return True
        # La resta d'usuaris: cal ser el lector del préstec
        return obj.lector == request.user


# bibliapp/api/views.py
from rest_framework import viewsets, status
from rest_framework.decorators import action
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated

from biblioteca.models import Llibre, Prestec
from .serializers import LlibreSerializer, PrestecSerializer
from .permissions import EsPropietariDelPrestec


class LlibreViewSet(viewsets.ModelViewSet):
    """
    ViewSet de Llibre: proporciona list, create, retrieve, update, destroy.
    El router genera automàticament /api/llibres/ i /api/llibres/{id}/.
    """
    serializer_class = LlibreSerializer
    permission_classes = [IsAuthenticated]

    def get_queryset(self):
        """
        Filtre dinàmic: ?disponible=true retorna
        només els llibres disponibles per a préstec.
        """
        qs = Llibre.objects.select_related('autor').all()
        disponible = self.request.query_params.get('disponible')
        if disponible is not None:
            # Convertim l'string 'true'/'false' a booleà
            qs = qs.filter(disponible=(disponible.lower() == 'true'))
        return qs

    @action(detail=False, methods=['get'], url_path='disponibles')
    def disponibles(self, request):
        """
        GET /api/llibres/disponibles/
        Retorna tots els llibres disponibles per a préstec.
        Acció addicional sobre la col·lecció (detail=False).
        """
        qs = self.get_queryset().filter(disponible=True)
        serializer = self.get_serializer(qs, many=True)
        return Response(serializer.data)


class PrestecViewSet(viewsets.ModelViewSet):
    """
    ViewSet de Prestec. L'usuari normal veu només els seus préstecs;
    l'admin veu tots.
    """
    serializer_class = PrestecSerializer
    permission_classes = [IsAuthenticated, EsPropietariDelPrestec]

    def get_queryset(self):
        """Filtra els préstecs: l'admin veu tot, l'usuari només els seus."""
        if self.request.user.is_staff:
            return Prestec.objects.select_related('llibre', 'lector').all()
        return Prestec.objects.select_related('llibre', 'lector').filter(
            lector=self.request.user
        )

    def perform_create(self, serializer):
        """
        En crear un préstec, assignem automàticament l'usuari autenticat
        com a lector — no cal que el client l'enviï.
        """
        serializer.save(lector=self.request.user)

    @action(detail=True, methods=['post'], url_path='retornar')
    def retornar(self, request, pk=None):
        """
        POST /api/prestecs/{id}/retornar/
        Marca el préstec com a retornat i allibera el llibre.
        Acció addicional sobre un objecte concret (detail=True).
        """
        prestec = self.get_object()  # aplica has_object_permission aquí

        if prestec.data_retorn:
            return Response(
                {'error': 'Aquest préstec ja ha estat retornat.'},
                status=status.HTTP_400_BAD_REQUEST
            )

        from datetime import date
        prestec.data_retorn = date.today()
        prestec.actiu = False
        prestec.save()

        # Alliberem el llibre perquè pugui tornar a ser prestat
        prestec.llibre.disponible = True
        prestec.llibre.save(update_fields=['disponible'])

        serializer = self.get_serializer(prestec)
        return Response(serializer.data, status=status.HTTP_200_OK)

from rest_framework import viewsets, status
from rest_framework.decorators import action
from rest_framework.permissions import IsAuthenticated, BasePermission
from rest_framework.response import Response
from books.models import Llibre, Prestec

class EsPropietariDelPrestec(BasePermission):
    def has_object_permission(self, request, view, obj):
        return obj.lector == request.user.lector

class LlibreViewSet(viewsets.ModelViewSet):
    serializer_class = LlibreSerializer
    permission_classes = [IsAuthenticated]

    def get_queryset(self):
        qs = Llibre.objects.select_related('autor')
        disponible = self.request.query_params.get('disponible')
        if disponible == 'true':
            qs = qs.filter(disponible=True)
        elif disponible == 'false':
            qs = qs.filter(disponible=False)
        return qs

class PrestecViewSet(viewsets.ModelViewSet):
    serializer_class = PrestecSerializer
    permission_classes = [IsAuthenticated, EsPropietariDelPrestec]

    def get_queryset(self):
        return Prestec.objects.filter(lector=self.request.user.lector)

    @action(detail=True, methods=['post'])
    def retornar(self, request, pk=None):
        prestec = self.get_object()
        if prestec.estat != 'actiu':
            return Response({'error': 'El préstec no és actiu.'}, status=400)
        from django.utils import timezone
        prestec.estat = 'retornat'
        prestec.data_retorn_real = timezone.now().date()
        prestec.save()
        return Response({'status': 'Préstec retornat correctament.'})

        if not value.disponible:
            raise serializers.ValidationError("El llibre no està disponible.")
        return value

    def validate_data_retorn_prevista(self, value):
        if value <= timezone.now().date():
            raise serializers.ValidationError("La data de retorn ha de ser futura.")
        return value

    def validate(self, attrs):
        request = self.context['request']
        if hasattr(request.user, 'lector'):
            actius = Prestec.objects.filter(lector=request.user.lector, estat='actiu').count()
            if actius >= 3:
                raise serializers.ValidationError("No es poden tenir més de 3 préstecs actius.")
        return attrs

    def create(self, validated_data):
        request = self.context['request']
        validated_data['lector'] = request.user.lector
        return super().create(validated_data)
