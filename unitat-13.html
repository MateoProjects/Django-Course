L'Admin de Django

El panell d'administració integrat: configura, personalitza i potencia la interfície per gestionar dades sense esforç.

En aquesta unitat aprendràs:

  • Registrar models amb admin.site.register() i el decorador @admin.register
  • Personalitzar llistes amb list_display, list_filter, search_fields i date_hierarchy
  • Organitzar formularis d'edició amb fieldsets i afegir models relacionats amb TabularInline
  • Crear accions personalitzades per operar sobre múltiples registres a la vegada

◆ Registrar models i configurar la vista de llista

L'admin de Django és una de les funcionalitats més potents del framework: amb molt poc codi tens una interfície d'administració completa i funcional. El punt d'entrada és el fitxer admin.py de cada aplicació, on indiques quins models vols exposar i com.

La forma bàsica és admin.site.register(Model), però el decorador @admin.register(Model) és la manera moderna i preferida: manté el model i la seva configuració junts en una sola classe. La classe ModelAdmin conté tots els atributs de configuració.

  • list_display — tupla de camps (o mètodes) que apareixen com a columnes a la llista. Pot incloure mètodes del model o de la classe ModelAdmin.
  • list_filter — camps per als quals es genera una barra de filtres lateral (booleants, dates, ForeignKey). Genera consultes automàtiques.
  • search_fields — camps on es fa la cerca de text lliure. Suporta __ per travessar relacions (p.ex. autor__nom).
  • readonly_fields — camps que es mostren en el formulari d'edició però no es poden modificar (útil per a dates automàtiques o camps calculats).
  • date_hierarchy — afegeix una navegació per dates a la part superior de la llista (any → mes → dia).
  • ordering — ordenació per defecte de la llista (sobreescriu el Meta.ordering del model).
  • list_per_page — nombre de registres per pàgina (per defecte 100). Redueix-lo si la pàgina carrega lent.
📌 Nota

Els mètodes usats a list_display poden tenir un atribut .short_description per canviar el títol de la columna, i .boolean = True per mostrar icones de check/creu en lloc de True/False.

Python admin.py — bibliapp complet 
from django.contrib import admin
from django.utils.html import format_html
from .models import Autor, Llibre, Lector, Prestec


@admin.register(Autor)
class AutorAdmin(admin.ModelAdmin):
    # Columnes visibles a la llista d'autors
    list_display  = ('nom', 'cognom', 'nacionalitat', 'num_llibres')
    list_filter   = ('nacionalitat',)
    search_fields = ('nom', 'cognom')
    ordering      = ('cognom', 'nom')

    def num_llibres(self, obj):
        """Mostra quants llibres té l'autor — mètode calculat."""
        return obj.llibres.count()
    num_llibres.short_description = 'Nre. de llibres'


@admin.register(Llibre)
class LlibreAdmin(admin.ModelAdmin):
    list_display    = ('titol', 'autor', 'any_publicacio', 'disponible_badge', 'idioma')
    list_filter     = ('disponible', 'idioma', 'any_publicacio')
    search_fields   = ('titol', 'autor__nom', 'autor__cognom', 'isbn')
    readonly_fields = ('data_creacio', 'data_modificacio')
    date_hierarchy  = 'data_creacio'
    ordering        = ('-any_publicacio',)
    list_per_page   = 25

    def disponible_badge(self, obj):
        """Mostra la disponibilitat com a badge de color."""
        if obj.disponible:
            return format_html(
                '<span style="color:#2ECC71;font-weight:bold">✓ Disponible</span>'
            )
        return format_html(
            '<span style="color:#FF6B35;font-weight:bold">✗ Prestat</span>'
        )
    disponible_badge.short_description = 'Estat'
    disponible_badge.allow_tags = True  # necessari per a HTML


@admin.register(Lector)
class LectorAdmin(admin.ModelAdmin):
    list_display  = ('nom_complet', 'email', 'data_registre', 'prestecs_actius')
    list_filter   = ('data_registre',)
    search_fields = ('nom', 'cognom', 'email')
    readonly_fields = ('data_registre',)

    def nom_complet(self, obj):
        return f"{obj.nom} {obj.cognom}"
    nom_complet.short_description = 'Nom complet'

    def prestecs_actius(self, obj):
        return obj.prestecs.filter(retornat=False).count()
    prestecs_actius.short_description = 'Préstecs actius'


@admin.register(Prestec)
class PrestecAdmin(admin.ModelAdmin):
    list_display  = ('llibre', 'lector', 'data_prestec', 'data_retorn_prevista', 'retornat')
    list_filter   = ('retornat', 'data_prestec')
    search_fields = ('llibre__titol', 'lector__nom', 'lector__cognom')
    readonly_fields = ('data_prestec',)
    date_hierarchy = 'data_prestec'

◆ Fieldsets, Inlines i Accions personalitzades

Quan edites un registre, per defecte tots els camps apareixen en un formulari pla. Amb fieldsets pots agrupar-los en seccions amb títol i descripció, millorant moltíssim la usabilitat per a administradors. Cada element del tuple és (nom_seccio, {opcions}), on les opcions inclouen 'fields', 'classes' (p.ex. 'collapse' per plegar la secció) i 'description'.

Les inlines permeten editar models relacionats directament des del formulari del model pare. TabularInline mostra cada registre en una fila d'una taula (compacte), mentre que StackedInline mostra cada registre en forma de formulari vertical (més espai, millor per a molts camps). Afegeix la classe inline a l'atribut inlines del ModelAdmin pare.

Les accions permeten operar sobre múltiples registres seleccionats a la llista. Es defineixen com a mètodes de la classe ModelAdmin (o funcions independents) i es registren a l'atribut actions. Reben (self, request, queryset) i la propietat .short_description defineix el nom que apareix al selector d'accions.

  • fieldsets — llista de tuples (títol, dict) per agrupar camps al formulari d'edició.
  • TabularInline — inline en format taula, ideal per a llistes de registres simples.
  • StackedInline — inline en format formulari, millor quan cada registre relacionat té molts camps.
  • extra — nombre de formularis buits extra que mostra l'inline (per defecte 3; posa'l a 0 per evitar formularis buits).
  • actions — llista de noms de mètodes (o funcions) que apareixeran al desplegable d'accions de la llista.
  • save_model(request, obj, form, change) — sobreescriu per afegir lògica extra en guardar (p.ex. registrar qui ha fet el canvi).
  • get_queryset(request) — sobreescriu per filtrar els registres visibles (útil per a admins amb accés limitat).
⚠️ Atenció

Les accions personalitzades han de tenir un atribut short_description o Django usarà el nom del mètode com a etiqueta, que normalment no és el que vols mostrar a l'usuari.

Python admin.py — Inlines i accions personalitzades 
from django.contrib import admin
from django.utils import timezone
from django.contrib import messages
from .models import Llibre, Prestec


class PrestecInline(admin.TabularInline):
    """Mostra els préstecs actius directament al formulari del Llibre."""
    model   = Prestec
    extra   = 0          # no mostrar files buides addicionals
    fields  = ('lector', 'data_prestec', 'data_retorn_prevista', 'retornat')
    readonly_fields = ('data_prestec',)

    def get_queryset(self, request):
        """Mostrar només els préstecs actuals (no retornats) a l'inline."""
        qs = super().get_queryset(request)
        return qs.filter(retornat=False)


def marcar_retornat(modeladmin, request, queryset):
    """Acció per marcar com a retornats tots els préstecs seleccionats."""
    actualitzats = 0
    for prestec in queryset.filter(retornat=False):
        prestec.retornat = True
        prestec.data_retorn_real = timezone.now().date()
        prestec.save()  # guardem un a un per activar signals si n'hi ha
        # restaurar disponibilitat del llibre associat
        prestec.llibre.disponible = True
        prestec.llibre.save()
        actualitzats += 1

    modeladmin.message_user(
        request,
        f"{actualitzats} préstec(s) marcats com a retornats correctament.",
        messages.SUCCESS
    )

marcar_retornat.short_description = "Marcar préstecs seleccionats com a retornats"


@admin.register(Llibre)
class LlibreAdmin(admin.ModelAdmin):
    list_display  = ('titol', 'autor', 'any_publicacio', 'disponible')
    list_filter   = ('disponible', 'idioma')
    search_fields = ('titol', 'autor__nom')
    inlines       = [PrestecInline]

    # Agrupem els camps en seccions al formulari d'edició
    fieldsets = (
        ('Informació bàsica', {
            'fields': ('titol', 'autor', 'isbn', 'any_publicacio', 'idioma')
        }),
        ('Disponibilitat', {
            'fields': ('disponible',),
            'description': 'Controla manualment si el llibre pot ser prestat.'
        }),
        ('Metadades', {
            'fields': ('data_creacio', 'data_modificacio'),
            'classes': ('collapse',),  # secció plegable per defecte
        }),
    )
    readonly_fields = ('data_creacio', 'data_modificacio')


@admin.register(Prestec)
class PrestecAdmin(admin.ModelAdmin):
    list_display  = ('llibre', 'lector', 'data_prestec', 'retornat')
    list_filter   = ('retornat',)
    actions       = [marcar_retornat]  # registrem l'acció aquí

    def save_model(self, request, obj, form, change):
        """Quan es guarda un préstec des de l'admin, marcar el llibre com no disponible."""
        super().save_model(request, obj, form, change)
        if not obj.retornat:
            obj.llibre.disponible = False
            obj.llibre.save()

# books/admin.py
from django.contrib import admin
from django.utils.html import format_html
from .models import Autor, Llibre, Prestec, Lector

class PrestecInline(admin.TabularInline):
    model = Prestec
    extra = 0
    readonly_fields = ['data_prestec', 'estat']
    fields = ['lector', 'data_prestec', 'data_retorn_prevista', 'estat']
    can_delete = False

@admin.register(Llibre)
class LlibreAdmin(admin.ModelAdmin):
    list_display = ['titol', 'autor', 'any_publicacio', 'genere', 'badge_disponible', 'num_pagines']
    list_filter = ['disponible', 'genere', 'any_publicacio']
    search_fields = ['titol', 'autor__cognoms', 'isbn']
    readonly_fields = ['created_at', 'slug']
    date_hierarchy = 'created_at'
    list_per_page = 25
    inlines = [PrestecInline]
    actions = ['marcar_disponibles', 'marcar_no_disponibles']

    @admin.display(description='Disponible', boolean=False)
    def badge_disponible(self, obj):
        if obj.disponible:
            return format_html('<span style="color:green">✓ Sí</span>')
        return format_html('<span style="color:red">✗ No</span>')

    @admin.action(description='Marcar com a disponibles')
    def marcar_disponibles(self, request, queryset):
        count = queryset.update(disponible=True)
        self.message_user(request, f'{count} llibre(s) marcats com a disponibles.')

    @admin.action(description='Marcar com a no disponibles')
    def marcar_no_disponibles(self, request, queryset):
        count = queryset.update(disponible=False)
        self.message_user(request, f'{count} llibre(s) marcats com a no disponibles.')

@admin.register(Prestec)
class PrestecAdmin(admin.ModelAdmin):
    list_display = ['llibre', 'lector', 'data_prestec', 'data_retorn_prevista', 'estat']
    list_filter = ['estat']
    actions = ['marcar_retornats']

    @admin.action(description='Marcar com a retornats')
    def marcar_retornats(self, request, queryset):
        from django.utils import timezone
        count = queryset.filter(estat='actiu').update(
            estat='retornat', data_retorn_real=timezone.now().date()
        )
        self.message_user(request, f'{count} préstec(s) marcat(s) com a retornats.')

PythonSolució completa
import logging
logger = logging.getLogger(__name__)

@admin.register(Llibre)
class LlibreAdmin(admin.ModelAdmin):
    fieldsets = (
        ('Informació bàsica', {'fields': ('titol', 'autor', 'isbn')}),
        ('Detalls', {'fields': ('any_publicacio', 'genere', 'num_pagines', 'disponible')}),
        ('Contingut', {'fields': ('descripcio',), 'classes': ['collapse']}),
        ('Metadades', {'fields': ('slug', 'created_at'), 'classes': ['collapse']}),
    )
    readonly_fields = ['created_at', 'slug']

    def save_model(self, request, obj, form, change):
        if not change:
            logger.info(f"Nou llibre creat: '{obj.titol}' per {request.user.username}")
        super().save_model(request, obj, form, change)

    def get_queryset(self, request):
        return super().get_queryset(request).select_related('autor')
