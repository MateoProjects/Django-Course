La capa de dades de Django: com definir l'estructura del món real en classes Python.

◆ Camps principals de Django

Un model Django és una classe Python que hereta de models.Model. Cada atribut de classe que sigui una instància d'un Field es mapeja a una columna de la base de dades. Django genera automàticament el camp id (clau primària) per a cada model tret que n'especifiquis un de propi amb primary_key=True.

Les opcions més importants que accepten quasi tots els camps:

  • blank=True — el camp pot estar buit en formularis de Django (validació de formulari)
  • null=True — la columna pot contenir NULL a la base de dades; per a CharField usa blank=True en lloc de null=True
  • default=valor — valor per defecte si no s'especifica; pot ser un callable (default=list)
  • unique=True — restricció d'unicitat a la base de dades
  • db_index=True — crea un índex a la base de dades per a cerques ràpides
  • verbose_name='...' — nom llegible per als formularis i l'admin
  • choices=LLISTA — restricció de valors possibles; mostra un select al formulari
  • auto_now_add=True — guarda la data/hora en el moment de creació; no es pot modificar
  • auto_now=True — actualitza la data/hora en cada save()
⚠️ null vs blank

Confondre null i blank és un error molt comú. null=True afecta la base de dades (permet NULL). blank=True afecta la validació de Django (permet camp buit en formularis). Per a camps de text (CharField, TextField), usa blank=True i Django guardarà una cadena buida "", no NULL. Reserva null=True per a camps numèrics, dates i relacions opcionals.

◆ Relacions entre Models

Django ofereix tres tipus de camps de relació que es corresponen amb els tres patrons de relació de bases de dades relacionals. Triar el tipus correcte és fonamental per a l'eficiència de les consultes i la integritat de les dades.

  • ForeignKey(Model, on_delete=...) — relació molts-a-un (N:1). Molts llibres poden tenir un mateix autor. El paràmetre on_delete és obligatori i defineix què passa quan s'esborra el registre relacionat.
  • OneToOneField(Model, on_delete=...) — relació un-a-un (1:1). Un lector té exactament un perfil extès. Útil per a dividir models grans o estendre el model User de Django.
  • ManyToManyField(Model) — relació molts-a-molts (N:M). Un llibre pot tenir múltiples gèneres i un gènere agrupa molts llibres. Django crea automàticament una taula intermèdia.
  • related_name='nom' — nom del accessor invers (de l'autor als seus llibres: autor.llibres.all()). Usa related_name='+' per deshabilitar l'accessor invers.
  • on_delete=CASCADE — quan s'esborra l'autor, s'esborren tots els seus llibres
  • on_delete=PROTECT — impedeix esborrar l'autor si té llibres associats (llança excepció)
  • on_delete=SET_NULL — posa el camp a NULL quan s'esborra el relacionat (requereix null=True)
  • on_delete=SET_DEFAULT — posa el valor per defecte quan s'esborra el relacionat
📌 La classe Meta

La classe interna Meta controla el comportament del model: ordering defineix l'ordre per defecte de les consultes, verbose_name i verbose_name_plural controlen els noms a l'admin, unique_together i constraints afegeixen restriccions compostes, i indexes crea índexos personalitzats.

Python books/models.py — models complets de bibliapp 
from django.db import models
from django.utils import timezone


class Autor(models.Model):
    """Autor d'un o més llibres de la biblioteca."""

    # choices: tupla de (valor_bd, etiqueta_llegible)
    NACIONALITAT_CHOICES = [
        ('CAT', 'Catalunya'),
        ('ESP', 'Espanya'),
        ('FRA', 'França'),
        ('GBR', 'Regne Unit'),
        ('USA', 'Estats Units'),
        ('ALT', 'Altra'),
    ]

    nom        = models.CharField(max_length=100, verbose_name='nom complet')
    cognoms    = models.CharField(max_length=150)
    # blank=True: el camp és opcional als formularis
    biografia  = models.TextField(blank=True, verbose_name='biografia')
    # null=True + blank=True: camp opcional, guardat com NULL si buit
    data_naix  = models.DateField(null=True, blank=True, verbose_name='data de naixement')
    nacionalitat = models.CharField(
        max_length=3,
        choices=NACIONALITAT_CHOICES,
        default='ALT',
    )
    # auto_now_add: s'omple sol en la creació, mai es pot canviar manualment
    creat_el   = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ['cognoms', 'nom']           # ordre per defecte a les consultes
        verbose_name = 'autor'
        verbose_name_plural = 'autors'

    def __str__(self):
        return f"{self.cognoms}, {self.nom}"

    def nom_complet(self):
        """Retorna el nom en format 'Nom Cognom' (ordre natural)."""
        return f"{self.nom} {self.cognoms}"


class Llibre(models.Model):
    """Exemplar d'un llibre al catàleg de la biblioteca."""

    ESTAT_CHOICES = [
        ('disponible', 'Disponible'),
        ('prestat',    'Prestat'),
        ('reservat',   'Reservat'),
        ('baixa',      'Baixa'),
    ]

    titol       = models.CharField(max_length=255)
    # ForeignKey: molts llibres → un autor
    # related_name permet accedir als llibres des de l'autor: autor.llibres.all()
    autor       = models.ForeignKey(
        Autor,
        on_delete=models.PROTECT,   # no permet esborrar autors amb llibres
        related_name='llibres',
    )
    isbn        = models.CharField(max_length=13, unique=True)
    # ManyToMany: un llibre pot tenir múltiples gèneres
    generes     = models.ManyToManyField(
        'Genere',
        blank=True,
        related_name='llibres',
    )
    sinopsi     = models.TextField(blank=True)
    any_publ    = models.PositiveIntegerField(
        verbose_name='any de publicació',
        null=True,
        blank=True,
    )
    pagines     = models.PositiveIntegerField(null=True, blank=True)
    estat       = models.CharField(
        max_length=20,
        choices=ESTAT_CHOICES,
        default='disponible',
        db_index=True,   # índex per a cerques freqüents per estat
    )
    portada     = models.ImageField(
        upload_to='portades/%Y/%m/',   # callable amb any i mes per organitzar fitxers
        null=True,
        blank=True,
    )
    # JSONField: flexibilitat per a metadades variables sense afectar l'esquema
    metadades   = models.JSONField(default=dict, blank=True)
    creat_el    = models.DateTimeField(auto_now_add=True)
    # auto_now: s'actualitza automàticament a cada save()
    modificat_el = models.DateTimeField(auto_now=True)

    class Meta:
        ordering = ['titol']
        verbose_name = 'llibre'
        verbose_name_plural = 'llibres'
        # Índex compost per a cerques habituals
        indexes = [
            models.Index(fields=['autor', 'estat'], name='idx_autor_estat'),
        ]

    def __str__(self):
        return f"{self.titol} ({self.autor.cognoms})"

    def esta_disponible(self):
        """Comprova si el llibre es pot prestar."""
        return self.estat == 'disponible'


class Genere(models.Model):
    """Gènere literari (Ficció, Assaig, Poesia, Infantil...)."""

    nom  = models.CharField(max_length=80, unique=True)
    slug = models.SlugField(max_length=80, unique=True)

    class Meta:
        ordering = ['nom']
        verbose_name = 'gènere'
        verbose_name_plural = 'gèneres'

    def __str__(self):
        return self.nom


class Lector(models.Model):
    """Usuari de la biblioteca que pot fer préstecs."""

    # OneToOneField: un lector ↔ un usuari Django
    # Si s'esborra l'usuari, s'esborra el lector (CASCADE)
    usuari      = models.OneToOneField(
        'auth.User',              # referència per string per evitar imports circulars
        on_delete=models.CASCADE,
        related_name='lector',
    )
    telefon     = models.CharField(max_length=20, blank=True)
    adreca      = models.TextField(blank=True)
    data_alta   = models.DateField(auto_now_add=True)
    actiu       = models.BooleanField(default=True)
    # Límit de préstecs simultanis configurable per lector
    max_prestecs = models.PositiveIntegerField(default=3)

    class Meta:
        verbose_name = 'lector'
        verbose_name_plural = 'lectors'

    def __str__(self):
        return f"Lector: {self.usuari.get_full_name() or self.usuari.username}"

    def prestecs_actius(self):
        """Retorna els préstecs actuals sense data de devolució."""
        return self.prestecs.filter(data_devolucio__isnull=True)


class Prestec(models.Model):
    """Registre d'un préstec d'un llibre a un lector."""

    lector      = models.ForeignKey(
        Lector,
        on_delete=models.PROTECT,
        related_name='prestecs',
    )
    llibre      = models.ForeignKey(
        Llibre,
        on_delete=models.PROTECT,
        related_name='prestecs',
    )
    data_prestec   = models.DateField(auto_now_add=True)
    data_limit     = models.DateField(verbose_name='data límit de devolució')
    # null=True: el préstec és actiu mentre no hi hagi data de devolució
    data_devolucio = models.DateField(null=True, blank=True)
    notes          = models.TextField(blank=True)

    class Meta:
        ordering = ['-data_prestec']
        verbose_name = 'préstec'
        verbose_name_plural = 'préstecs'
        # Un lector no pot tenir el mateix llibre dues vegades simultàniament
        constraints = [
            models.UniqueConstraint(
                fields=['lector', 'llibre'],
                condition=models.Q(data_devolucio__isnull=True),
                name='uq_prestec_actiu',
            )
        ]

    def __str__(self):
        return f"{self.llibre.titol} → {self.lector} ({self.data_prestec})"

    def esta_actiu(self):
        """El préstec és actiu si no s'ha retornat."""
        return self.data_devolucio is None

    def esta_en_retard(self):
        """El préstec ha superat la data límit sense retornar."""
        if self.data_devolucio:
            return False
        return timezone.now().date() > self.data_limit

◆ Camps personalitzats

Django permet crear camps a mida subclassant models.Field. Això és útil quan cap camp built-in satisfà la necessitat, com ara transformar automàticament el valor en guardar-lo o llegir-lo, validar un format específic, o encapsular lògica de serialització. El mètode from_db_value transforma en llegir de la base de dades, i get_prep_value transforma en guardar.

Python books/fields.py — camp personalitzat UpperCaseField 
"""
Camp personalitzat que guarda el text en majúscules a la base de dades.
Inspirat en patrons del món real (p. ex. codis ISBN, matrícules, codis país).

Referència avançada: MediNetHub usa EncryptedTextField, que segueix el mateix
patró però xifra/desxifra el valor amb una clau Fernet.
"""
from django.db import models


class UpperCaseField(models.CharField):
    """
    CharField que converteix automàticament el valor a majúscules.

    Ús:
        class Pais(models.Model):
            codi = UpperCaseField(max_length=3)
            # pais.codi = 'esp' → guardat com 'ESP'
    """

    # description és el text que apareix als esquemes i a l'admin
    description = "Text guardat sempre en majúscules"

    def get_prep_value(self, value):
        """
        Crida just ABANS de guardar a la base de dades.
        Aquí és on apliquem la transformació.
        """
        value = super().get_prep_value(value)
        if value is not None:
            return value.upper()
        return value

    def from_db_value(self, value, expression, connection):
        """
        Crida just DESPRÉS de llegir de la base de dades.
        En aquest cas ja és majúscules, però podria fer desxifrat, etc.
        """
        if value is not None:
            return value.upper()
        return value

    def to_python(self, value):
        """
        Crida en la deserialització i validació de formularis.
        """
        value = super().to_python(value)
        if value is not None:
            return value.upper()
        return value

class ISBNField(models.CharField):
    """Camp que valida el format ISBN-13."""

    def __init__(self, *args, **kwargs):
        # Fixem max_length a 13 per a tots els ISBNField
        kwargs.setdefault('max_length', 13)
        super().__init__(*args, **kwargs)

    def validate(self, value, model_instance):
        super().validate(value, model_instance)
        # Validació de dígit de control ISBN-13
        if len(value) != 13 or not value.isdigit():
            from django.core.exceptions import ValidationError
            raise ValidationError(
                f"'{value}' no és un ISBN-13 vàlid (ha de tenir 13 dígits)"
            )
🔮 Nota avançada

Quan creïs un camp personalitzat, afegeix sempre el mètode deconstruct() si el camp accepta paràmetres propis. Sense ell, les migracions no podran reconstruir correctament el camp. Consulta la documentació de Django sobre "Writing custom model fields".

# books/fields.py
from django.db import models

class UpperCaseField(models.CharField):
    def pre_save(self, model_instance, add):
        valor = getattr(model_instance, self.attname)
        if valor:
            valor_upper = valor.upper()
            setattr(model_instance, self.attname, valor_upper)
            return valor_upper
        return valor
