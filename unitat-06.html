Vistes Basades en Funcions

La forma més directa de respondre a peticions HTTP: una funció Python que rep un request i retorna una response.

En aquesta unitat aprendràs:

  • Entendre l'objecte request i tots els seus atributs útils
  • Usar render(), redirect() i get_object_or_404() correctament
  • Implementar un CRUD complet amb FBV per al model Llibre
  • Protegir vistes amb decoradors i retornar respostes JSON

◆ La funció vista i l'objecte request

Tota vista Django és, en essència, un callable que rep un objecte HttpRequest i retorna un objecte HttpResponse. En les vistes basades en funcions (FBV), aquest callable és literalment una funció Python. La simplicitat és el seu major avantatge: és fàcil llegir-les, depurar-les i testejar-les.

L'objecte request conté tota la informació de la petició entrant. Saber quins atributs ofereix és fonamental per escriure vistes correctes:

  • request.method — cadena amb el mètode HTTP: 'GET', 'POST', 'PUT', 'DELETE'
  • request.GET — diccionari amb els paràmetres de la query string (?cerca=django)
  • request.POST — diccionari amb les dades del formulari enviat per POST
  • request.FILES — fitxers pujats via formulari multipart
  • request.user — l'usuari autenticat (o AnonymousUser si no ho està)
  • request.session — diccionari persistent per a la sessió de l'usuari
  • request.META — capçaleres HTTP i variables d'entorn del servidor
  • request.body — cos de la petició en bytes (útil per JSON via json.loads(request.body))
  • request.path — la ruta URL de la petició actual (p.ex. /books/3/)

Les tres funcions d'ajuda que usaràs en el 90% de les vistes:

  • render(request, template, context) — renderitza un template amb el context donat i retorna un HttpResponse
  • redirect(url_o_vista) — retorna un HttpResponseRedirect (codi 302); accepta URL, nom de vista o objecte amb get_absolute_url()
  • get_object_or_404(Model, **kwargs) — com .get() però llança un 404 automàtic si no existeix; evita blocs try/except repetitius
📌 Nota

El patró if request.method == 'POST': dins d'una única funció és la manera idiomàtica Django d'unificar la vista de GET (mostrar formulari) i POST (processar formulari) en un sol lloc.

Python books/views.py — CRUD complet amb FBV 
from django.shortcuts import render, redirect, get_object_or_404
from django.contrib.auth.decorators import login_required
from django.contrib import messages
from django.views.decorators.http import require_http_methods

from .models import Llibre, Autor
from .forms import LlibreForm


def llistar_llibres(request):
    """Mostra tots els llibres; permet filtrar per títol via query string."""
    cerca = request.GET.get('cerca', '')  # ?cerca=quijote → 'quijote' o ''

    llibres = Llibre.objects.select_related('autor').order_by('titol')
    if cerca:
        llibres = llibres.filter(titol__icontains=cerca)

    return render(request, 'books/llista.html', {
        'llibres': llibres,
        'cerca': cerca,
    })


def detall_llibre(request, pk):
    """Mostra el detall d'un llibre o retorna 404 si no existeix."""
    # get_object_or_404 és equivalent a Llibre.objects.get(pk=pk)
    # però retorna automàticament una pàgina 404 si no es troba.
    llibre = get_object_or_404(Llibre, pk=pk)
    return render(request, 'books/detall.html', {'llibre': llibre})


@login_required  # Redirigeix a /accounts/login/ si no estàs autenticat
def crear_llibre(request):
    """Mostra el formulari (GET) o processa la creació (POST)."""
    if request.method == 'POST':
        form = LlibreForm(request.POST)
        if form.is_valid():
            llibre = form.save()
            # Missatge flash que es mostra a la propera pàgina
            messages.success(request, f'Llibre "{llibre.titol}" creat correctament.')
            return redirect('books:detall', pk=llibre.pk)
    else:
        # GET: mostrem el formulari buit
        form = LlibreForm()

    return render(request, 'books/formulari.html', {'form': form, 'accio': 'Crear'})


@login_required
def actualitzar_llibre(request, pk):
    """Actualitza un llibre existent."""
    llibre = get_object_or_404(Llibre, pk=pk)

    if request.method == 'POST':
        # instance=llibre fa que form.save() actualitzi, no creï
        form = LlibreForm(request.POST, instance=llibre)
        if form.is_valid():
            form.save()
            messages.success(request, 'Llibre actualitzat.')
            return redirect('books:detall', pk=pk)
    else:
        # GET: formulari pre-emplenat amb les dades actuals
        form = LlibreForm(instance=llibre)

    return render(request, 'books/formulari.html', {
        'form': form,
        'llibre': llibre,
        'accio': 'Actualitzar',
    })


@login_required
@require_http_methods(['POST'])  # Rebutja GET, PUT, etc. amb 405 Method Not Allowed
def esborrar_llibre(request, pk):
    """Esborra un llibre. Només accepta POST per seguretat."""
    llibre = get_object_or_404(Llibre, pk=pk)
    titol = llibre.titol
    llibre.delete()
    messages.warning(request, f'Llibre "{titol}" esborrat.')
    return redirect('books:llista')

◆ Decoradors, sessions i respostes JSON

Els decoradors permeten afegir comportament a les vistes sense modificar-ne el cos. Django inclou una col·lecció de decoradors molt útils al mòdul django.contrib.auth.decorators i django.views.decorators.http.

  • @login_required — redirigeix a settings.LOGIN_URL si l'usuari no està autenticat; accepta login_url='/acces/' per personalitzar-ho
  • @require_http_methods(['GET', 'POST']) — llença 405 si el mètode no és als permesos; alternativa: @require_GET, @require_POST
  • @permission_required('books.add_llibre') — comprova si l'usuari té el permís indicat
  • @cache_page(60 * 15) — desa la resposta en memòria cau durant 15 minuts

Per a APIs lleugeres sense DRF, JsonResponse és tot el que necessites. Hereta d'HttpResponse però serialitza automàticament un diccionari a JSON i estableix el Content-Type: application/json.

  • JsonResponse({'ok': True}) — resposta JSON simple
  • JsonResponse({'error': 'No trobat'}, status=404) — amb codi d'estat personalitzat
  • JsonResponse(list(qs.values()), safe=False) — per serialitzar llistes (cal safe=False)
  • request.session['clau'] = valor — desa dades a la sessió de l'usuari
  • request.session.get('clau', default) — llegeix de la sessió (com un diccionari)
⚠️ Seguretat

Quan parseges request.body com a JSON, envolta-ho sempre en un bloc try/except json.JSONDecodeError. Un cos mal format pot causar un 500 si no ho gestiones.

Python books/views.py — API JSON i ús de sessió 
import json
from django.http import JsonResponse, HttpResponse
from django.views.decorators.http import require_http_methods
from django.views.decorators.csrf import csrf_exempt

from .models import Llibre


def api_llibres(request):
    """Endpoint que retorna la llista de llibres en format JSON."""
    # values() retorna QuerySet de dicts, que JsonResponse pot serialitzar
    llibres = list(
        Llibre.objects.select_related('autor')
        .values('id', 'titol', 'isbn', 'disponible', 'autor__nom')
    )
    # safe=False és obligatori quan el valor arrel és una llista
    return JsonResponse({'count': len(llibres), 'results': llibres}, safe=False)


@require_http_methods(['POST'])
def api_cerca(request):
    """Cerca llibres a partir d'un JSON al cos de la petició.

    Espera: {"terme": "django"}
    Retorna: {"count": N, "results": [...]}
    """
    try:
        dades = json.loads(request.body)
    except json.JSONDecodeError:
        return JsonResponse({'error': 'JSON invàlid al cos de la petició'}, status=400)

    terme = dades.get('terme', '').strip()
    if not terme:
        return JsonResponse({'error': 'Cal enviar el camp "terme"'}, status=422)

    resultats = list(
        Llibre.objects.filter(titol__icontains=terme).values('id', 'titol')
    )
    return JsonResponse({'count': len(resultats), 'results': resultats})


def afegir_a_llista_desitjos(request, pk):
    """Guarda l'id d'un llibre a la sessió de l'usuari."""
    # La sessió és persistent entre peticions del mateix navegador
    llista = request.session.get('desitjos', [])

    if pk not in llista:
        llista.append(pk)
        # Hem de reassignar la llista perquè Django detecti el canvi
        request.session['desitjos'] = llista
        return JsonResponse({'afegit': True, 'total': len(llista)})

    return JsonResponse({'afegit': False, 'total': len(llista)})


def mostrar_llista_desitjos(request):
    """Mostra els llibres desats a la sessió."""
    ids = request.session.get('desitjos', [])
    llibres = Llibre.objects.filter(pk__in=ids)
    return render(request, 'books/desitjos.html', {'llibres': llibres})
🔮 Nota avançada

La sessió de Django per defecte es desa a la base de dades (taula django_session). Pots canviar el backend a Redis o a cookies signades ajustant SESSION_ENGINE a settings.py. Per a producció, Redis és l'opció recomanada.

# books/views.py
from django.shortcuts import render, redirect, get_object_or_404
from django.contrib.auth.decorators import login_required
from django.contrib import messages
from django.views.decorators.http import require_http_methods
from .models import Llibre, Prestec
from .forms import PrestecForm

@login_required
def llistar_llibres(request):
    disponible = request.GET.get('disponible')
    qs = Llibre.objects.select_related('autor')
    if disponible == 'si':
        qs = qs.filter(disponible=True)
    elif disponible == 'no':
        qs = qs.filter(disponible=False)
    return render(request, 'books/llistar_llibres.html', {'llibres': qs})

@login_required
def detall_llibre(request, pk):
    llibre = get_object_or_404(Llibre, pk=pk)
    return render(request, 'books/detall_llibre.html', {'llibre': llibre})

@login_required
def crear_prestec(request, llibre_pk):
    llibre = get_object_or_404(Llibre, pk=llibre_pk, disponible=True)
    if request.method == 'POST':
        form = PrestecForm(request.POST)
        if form.is_valid():
            prestec = form.save(commit=False)
            prestec.llibre = llibre
            prestec.lector = request.user.lector
            prestec.save()
            messages.success(request, f'Préstec creat per "{llibre.titol}"')
            return redirect('books:detall_llibre', pk=llibre.pk)
    else:
        form = PrestecForm()
    return render(request, 'books/crear_prestec.html', {'form': form, 'llibre': llibre})

@login_required
@require_http_methods(["POST"])
def esborrar_prestec(request, pk):
    prestec = get_object_or_404(Prestec, pk=pk, lector=request.user.lector)
    titol = prestec.llibre.titol
    prestec.delete()
    messages.warning(request, f'Préstec de "{titol}" eliminat.')
    return redirect('books:llistar_llibres')

from django.http import JsonResponse
from django.contrib.auth.decorators import login_required
from django.db.models import Count
from .models import Llibre, Prestec, Autor

@login_required
def estadistiques_json(request):
    top_autors = list(
        Autor.objects.annotate(total=Count('llibres'))
        .order_by('-total')[:3]
        .values('nom', 'cognoms', 'total')
    )
    dades = {
        'total_llibres': Llibre.objects.count(),
        'llibres_disponibles': Llibre.objects.filter(disponible=True).count(),
        'prestecs_actius': Prestec.objects.filter(estat='actiu').count(),
        'top_autors': top_autors,
    }
    return JsonResponse(dades)

Funcions d'ajuda

  • render() — template → HttpResponse
  • redirect() — 302 a URL o vista
  • get_object_or_404() — get() + 404
  • JsonResponse() — dict → JSON
  • HttpResponse() — resposta bàsica

Decoradors clau

  • @login_required — autenticació
  • @require_http_methods — mètodes
  • @require_POST — només POST
  • @permission_required — permisos
  • @cache_page — memòria cau
